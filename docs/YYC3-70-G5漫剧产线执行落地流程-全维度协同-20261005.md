## 二、执行总览（三阶段流水）

```text
Phase A 技术前置（1 会话量级，数据底座）
  A1 质检补齐（抽帧+电平） → A2 码率口径校准 → A3 batches schema v2
        ↓ （完成后解锁 B 的台账配置与量产质检）
Phase B 运营双线并行（日历 ~2 周，G5 判定唯一路径）
  判定线：B0 开号(人工) → B1 P0 窗口 7天 → B2 P1 窗口 7天 → B3 judge+gate 收割
  建议线：Agent 运营报告组（伯乐+万物+先知）→ 排期建议 → 台账 source 升级
        ↓ （B 等待期并行）
Phase C 智能化跟进（窗口期填充）
  C1 分发就绪门禁工具化 → C2 平台字幕烧入 → C3 裁切口径标定
        ↓
G5 解除 Blocked → 转 YYC3-67 §六阶段二（全链路智能化，1-2 月）
```

**关键红线（贯穿全程）**：判定域只认真实曝光数据；Agent 报告属建议供给层（69 §2.7 v1.1.0）；质检 <80 打回、复检 ≤2 轮；不虚构、不盲测、留证落盘。

## 三、Phase A · 技术前置（P0，依据 68 §8.4 P0 三项）

| # | 任务 | 执行步骤 | 负责 | 验收标准 |
| - | ---- | -------- | ---- | -------- |
| A1 | 质检诊断补齐 | ① 读 run_quality_review.py 五维结构 → ② 增 `black_frames_5pt`（成片 5 位等距抽帧 blackdetect）+ `audio_level`（volumedetect mean/max）为独立 diagnostics 节，**不动五维分数** → ③ 六集复跑留证 | 工程（格物·宗师挂载） | 输出含新字段；sdxl-prod 六集复跑全 PASS；产物落 docs/attachments/ |
| A2 | 码率口径校准 | 决策二选一：**甲（推荐）**=规范修订为 ≥128k（语音向内容听感足够，零重渲）；乙=升 192k 六集重渲+复验。决策后同步 68 附录B 与质检标准 | 用户拍板 + 工程 | 规范条文与 `-b:a` 实参一致；质检判定标准同步修订 |
| A3 | batches schema v2 | 按 68 §7.3 三步：① batch 项增 `seed_list/aspect_profiles/active_profiles/quality_gate/schedule` + `schema_version` 递增（additionalProperties:false 保持全显式）② 双形态并存（stats/plan 分离或 params 过渡）③ 质检/gate 产物回写 `avgScore/maxScore/defects` | 工程（h3 生成仓；元启·天枢消费） | 新旧 batches 双过 schema 校验；run_g5_gate 回归无退化 |

**依赖关系**：A1/A3 无前置可并行；A2 独立。A3 完成是 B2 伯乐建议结构化注入（suggestions 契约）的前置。

4. 资产取用：归档区 `~/YYC-Cube/YYC3-assets/projects/sdxl-prod-00X/output/`（横 `_full` / 竖 `_v916_native`）
