# 故障模式手册（38 轮教训结构化）

> 对标 OnlyShot「17 种失败模式与解法」沉淀口径（63 号 A4 落位）。
> 素材来源：HANDOFF 三十八章执行日志 + 各轮留证 JSON。**新增条目随轮次追加，禁止口头传承。**

## 一、基础设施层（I 系列）

| ID | 现象 | 根因 | 解法 | 预防 | 出处 |
| -- | ---- | ---- | ---- | ---- | ---- |
| I-01 | ComfyUI 文生图 400 | adapter 默认模型 sd_xl_base 不在实机 | `COMFYUI_MODEL=DreamShaper_8_pruned.safetensors` 显式注入 | 新环境先探 `GET /object_info/CheckpointLoaderSimple` | 35.2 轮 |
| I-02 | HF 模型下载超时（exit 28） | huggingface.co 直连不可达 | 切 hf-mirror.com 镜像；先 HEAD 校验 Content-Length 再落盘 | 下载前 HEAD 对账字节数 | 35.4 轮 |
| I-03 | 1024px 生产生成 300s 超时 | 大分辨率排队+推理时长超预设 | `COMFYUI_TIMEOUT>=700`；首轮超时勿急杀（队列排队非死锁） | 生产口径统一 env 注入 | 37 轮 G4-006 |
| I-04 | Milvus 未装 import 即断流 | 一致性引擎顶层依赖不可卸载 | ModuleType 动态 stub 注入（`sys.modules`） | 新依赖接入必配 stub 降级路径 | M3 轮 |
| I-05 | 公网 URL 全部拒连 | SSRF 三道闸白名单未含目标 | 内网白名单登记（协议/主机/解析 IP） | 外部端点接入先过闸配置 | adapter 首版 |
| I-06 | GB10 并行训练卡死 | GPU 串行化限制并发 CUDA 上下文 | 训练/推理任务串行队列，禁并发 | n1 夜间窗口单任务纪律 | G2 轮 |
| I-07 | 会话中断后 /tmp 产物全丢 | 系统清理 /tmp，脚本硬编码作工作区 | 产物即产即归档 `docs/attachments/`；工作区目录先 mkdir | 关键产物落 REPO 内 | 35.4/36 轮 |

## 二、生成模型层（M 系列）

| ID | 现象 | 根因 | 解法 | 预防 | 出处 |
| -- | ---- | ---- | ---- | ---- | ---- |
| M-01 | 跨日重生成相似度塌方（sim 0.5675） | 参考系漂移：seed42 重建图随 ComfyUI 环境更新偏移，评测全线误判 | 评测锚定历史设定图本体（`ComfyUI/input/hero_base.png`）；库向量仲裁校准 1.0 | 跨日对比前先校准参考系；禁 /tmp 生成图作跨日参考 | 35.4 轮（八项证伪之二） |
| M-02 | 评测可疑低分误判模型劣化 | 参考系错误而非模型问题 | 先重测基线（v2 本体）定位参考系，再裁模型 | 评测裁决前必跑基线复现 | 35.4 轮 |
| M-03 | 全部产物 2.1s 完成 | 节点缓存命中非真实推理 | md5 互异验证产物真实性 | 冒烟计时异常先验 md5 | 35.4 轮 |
| M-04 | FaceID 组合复跑漂移疑虑 | 评测与生产工作流参数不一致 | 逐参镜像生产 KSampler/负面词/CLIP 链 | 评测工作流=生产工作流逐参对齐 | 36 轮 G4-006 |
| M-05 | SDXL 系身份模型接入即失败 | InstantID/PuLID 为 SDXL 专属，基模是 SD15 | 基模迁移独立排期（YYC3-62 三阶段），不混搭 | 模型选型先查基模代际兼容 | 35.4 勘察 |

## 四、工程管线层（E 系列）

| ID | 现象 | 根因 | 解法 | 预防 | 出处 |
| -- | ---- | ---- | ---- | ---- | ---- |
| E-01 | on_event 弃用警告 | FastAPI 旧生命周期 API | lifespan 迁移（提交 234306d） | 依赖升级后跑 deprecation 全检 | #problems 轮 |
| E-02 | pyright PIL 导入误报 | venv 错配（网关依赖 vs scripts 依赖两套环境） | pyrightconfig executionEnvironments 按目录分流 + import ignore 标注 | 多 venv 仓库必配环境分流 | #problems 轮（4ee4eab） |
| E-03 | shutil.rmtree 无条件清空共享特征库 | 多角色互删风险（首审 P1-11） | 仅清本角色目录（save_character 自包含重建） | 破坏性操作必须最小作用域 | 首审 P1-11 |
| E-04 | 新脚本写 state 目录 FileNotFoundError | 项目目录未初始化 | mkdir parents 前置（candidates 脚本已修） | 脚本入口统一目录初始化段 | 39 轮 A3 |
| E-05 | 结果误报「自批判 75.1 pass」（真实 **66.3 revise**） | `cmd \| tail; echo $?` 取到的是 **tail 的退出码**而非执行器返回码；且得分未回读留证 JSON 复核 | 回读留证 JSON 字段更正（HANDOFF 39.1 / 63 号回执） | 管道后取退出码必须用 `${PIPESTATUS[0]}` 或先落变量；**一切结论以留证 JSON 为准，不凭终端观感** | 39/40 轮更正 |
| E-06 | 前置闸默认 block 会恒定阻断夜批 | 基线分镜 66.3 < 阈值 70，闸门「永远不过」即等于停摆 | 增 `--gate-mode {warn,block}`，默认 warn（告警留证放行），待分镜优化过闸再切 block | 闸门上线前先测基线通过率；硬闸必须配模式开关 | 40 轮 A6 接入 |

## 五、使用纪律

1. **排障顺序**：先对症状定位系列（I/M/D/E）→ 查表 → 按解法执行 → 预防项落配置。
2. **新故障入库**：解法验证后按模板追加，留证 JSON 链接入出处列；同根因合并编号。
3. **红线关联**：M-01/M-03 涉及评测可信度，属八项证伪台账同源纪律，违反即结果无效。
4. 本手册与 [YYC3-61 指导目录](YYC3-61-AI漫剧全链路闭环生产操作指导目录.md)附录快速恢复命令卡配合使用。
