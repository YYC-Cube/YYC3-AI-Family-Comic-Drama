# M1 决议：A2 音频码率基线（甲方案）+ 热重载实态适配

## 一、决议结论（已批复）

**采纳【甲方案】**：语音向漫剧音频基线 = **AAC ≥128kbps**（目标值），存量六集**无需重渲、无需复验重跑全链**，直接放行平台投放；**M1 里程碑正式收口**，资源进入 G5 投放阶段（存量三版资产投放 + 新批次一源多投双画幅）。

规范分层：

| 分支 | 触发 | 目标码率 | 校验阈值（带 VBR 容差） |
| ---- | ---- | -------- | ---------------------- |
| 默认基线（语音向主线） | 缺省 | 128k AAC | **≥120,000 bps** |
| 高音质分支（标记式启用） | `batches.audio_high_quality: true` / CLI `--audio-hq` | 192k AAC | **≥184,000 bps** |

> 适用场景（高音质分支）：密集配乐、多层动态音效、典藏母带、广播剧衍生。短视频平台存在二次转码压缩，192k 在终端听感增益有限，仅资产归档/多媒介衍生启用，避免无差别增加算力。

## 二、关键实证：AAC VBR 容差修正（对原方案的技术修订）

**原方案 `bitrate_min: 128000` 严格阈值会误杀**。实测（2026-10-05，六集 × 横版/原生竖版 12 产物）：

```
音频流实际码率分布：127,295 – 128,578 bps（ffmpeg -b:a 128k 的 AAC VBR 输出）
其中 9/12 低于 128,000 —— 严格阈值下六集成片大半会被 A2 误判 FAIL
```

**修正**：基线阈值取 120,000（-6.25% 容差，全覆盖实测下界且仍能拦截 96k/64k 真低码率）；高音质分支同例 184,000。该修正已固化进质检实现与规则 YAML。

## 四、热重载设计（Agent 化阶段二项 · 设计稿定版）

> **实态定位**：当前质检为 CLI 范式（run_quality_review.py 无状态执行）——**每次执行即加载最新规则，天然热生效，无重载需求**。以下热重载机制在 Agent 常驻集群（YYC3-67 §六阶段二）落地时启用；当前 CLI→Agent 迁移期本节作为实现规格。

### 4.1 重载通道（双通道设计）

**主通道 HTTP**（网关内置路由）：

- `POST /agent/gewuzongshi/reload_quality_rules`（网关统一 JWT 鉴权，密钥环境变量注入）
- 请求体：`{"rule_file", "version_tag", "dry_run", "trace_id"}`
- `dry_run:true` 预检（只解析校验不生效，防 YAML 语法错误炸质检）→ 通过后 `dry_run:false` 正式热替换

**备选通道 Redis PubSub**（A2A 原生适配）：

- 控制流 `stream:agent:control:gewuzongshi`，消息 `{"cmd":"RELOAD_QUALITY_RULES", "version", "dry_run", "initiator_agent":"yuanqi-tianshu", "trace_id"}`
- 审计流 `stream:agent:audit` 由智云·守护留存
- 权限：仅元启·天枢或运维密钥可下发；普通 Agent 不可改质检规则

### 4.2 任务隔离（关键边界）

- **在途任务沿用旧规则**（加载时刻快照，防批次中途校验逻辑突变）；**新入队任务自动用新版**
- 版本锁：规则文件自带 `rule_version`，重载校验版本标记防加载旧文件
- 事务保护：YAML 校验失败维持内存旧规则不变（不降级不半生效）
- 一键回滚：改版本号再热重载一次，全程无进程重启

### 4.3 规则管理器核心逻辑（QualityRuleManager 精简实现规格）

```python
class QualityRuleManager:
    def hot_reload(self, dry_run: bool = False):
        new_raw = yaml.safe_load(self.rule_path.read_text(encoding="utf-8"))
        self._validate(new_raw)          # 强校验：阈值必须 int、字段完整
        if dry_run:
            return {"status": "dry_run_ok", "new_version": new_raw["A2"]["rule_version"]}
        self.rules, self.active_version = new_raw, new_raw["A2"]["rule_version"]
        return {"status": "reload_success", "active_version": self.active_version}
```
