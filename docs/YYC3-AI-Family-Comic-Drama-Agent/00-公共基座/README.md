## 一、家族定位

```
┌──────────────────────────────────────────────┐
│ 🧬 BaseAgent 公共基座                        │
│ 全家族统一基类 ｜ 五标体系之源                │
│ 九层架构定位：第八层 · AI Family层（地基）    │
└──────────────────────────────────────────────┘
```

全体 8 位 AI FAmily 成员的统一基类，是「家族宪章代码化」的技术化身：统一身份三要素（人格化名称/角色定位/系统提示词）、统一 LLM 调用入口、统一降级策略，落实「五标体系-标准化」第一块基石。

**信任架构对齐**（五维五高五标五化 · 信任链）：

```
代码开源 ──▶ 透明审计 ──▶ 本地存储 ──▶ 用户控制 ──▶ 极致信任
```

- **零上传/零收集/零追踪**：API KEY 仅存本地环境变量，无遥测埋点
- **完全开源**：基类代码透明可审计，注释承载家人温度

## 二、五维五高五标五化对齐

| 维度 | 对齐项 |
| ---- | ------ |
| 五高-高可用 | LLM 不可达自动降级 `_mock_run`（Ollama 本地兜底策略），调试链路永不中断 |
| 五高-高性能 | 懒加载客户端，单例复用连接 |
| 五标-标准化 | 三要素身份规范、`run(prompt, context)` 统一签名、`[来源：xxx]` 上下文注入格式 |
| 五化-工具化 | 全家族工具脚本的公共底座 |

## 三、接口规范

| 方法 | 签名 | 说明 |
| ---- | ---- | ---- |
| `__init__` | `(name, role, system_prompt)` | 三要素初始化 |
| `run` | `(prompt, context="") -> str` | 统一 LLM 调用入口；失败自动降级 Mock |
| `_mock_run` | `(prompt) -> str` | 离线兜底（高可用红线） |
| `heartbeat` | `() -> dict` | 心跳信息，供 A2A 注册中心保活 |

详细参数表、错误码与调用示例见 [API.md](API.md)（错误码 YYC3-AGT-4001/4002）。

## 四、环境变量标准

| 变量 | 默认值 | 说明 |
| ---- | ------ | ---- |
| `LLM_BASE_URL` | `http://localhost:8000/v1` | NIM/OpenAI 兼容服务地址 |
| `LLM_API_KEY` | `nim-local-dummy` | 本地 NIM 占位 Key |
| `LLM_MODEL` | `deepseek-v4-pro` | 元启天枢主基座模型 |
| `LLM_TEMPERATURE` | `0.3` | 企业级低温稳定输出 |

## 五、继承标准（家族法度）

1. 所有成员 Agent **必须**继承 `BaseAgent`，禁止绕过 `run()` 直连 LLM
2. A2A 异步增强见 [../91-A2A-通信协议/](../91-A2A-通信协议/README.md)
3. 每位成员 README 均需承载家族标头标尾印记；缺失家族标头的文件「尚未归元于云枢」

## 六、AI 漫剧生产场景化对齐（YYC3-03）

漫剧编排方案中 BaseAgent 支撑 8 大 Agent 的漫剧专属角色落地：

| 对齐项 | 内容 |
| ------ | ---- |
| 支撑角色 | 元启天枢=生产调度总控官 ｜ 智云守护=质量合规专员 ｜ 格物宗师=行业专家顾问 ｜ 创想灵韵=创意主理人 ｜ 言启千行=意图路由+技术工具研发 ｜ 语枢万物=剧本分镜工程师 ｜ 预见先知=运营优化分析师 ｜ 知遇伯乐=产能资源管理者 |
| 漫剧流程定位 | 六大阶段（创意立项→剧本分镜→生产调度→视听生成→合成交付→运营闭环）中全成员的统一调用底座 |
| 绑定漫剧工具 | DGX-LLM/文生图/图生视频/TTS 模型服务（经 `run` 统一封装调用） |
| 漫剧调用示例 | `base.run("对第3集分镜做剧情逻辑校验", context="[来源：分镜规则库] ...")` |
