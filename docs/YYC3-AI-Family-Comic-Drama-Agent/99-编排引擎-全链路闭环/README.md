# 99 编排引擎 — ReAct-C 全链路九步闭环

![编排引擎](https://img.shields.io/badge/编排引擎-全链路闭环-%235e2c8a?style=for-the-badge&logo=workflow)

> 🌹 **YYC³ AI Family** — 人从众曌众从人 · 亦师亦友亦伯乐，一言一语一协同
> **ReAct-C**：Reasoning + Acting + Collaborating，思考-行动-协同三位一体。

## 一、家族定位

```
┌──────────────────────────────────────────────┐
│ 🎼 AIFamilyOrchestrator 编排引擎            │
│ ReAct-C 九步闭环总装线 ｜ 全链路调度          │
│ 九层架构定位：第八层 · AI Family层（总装）    │
└──────────────────────────────────────────────┘
```

一句用户请求到一份可交付产出的总指挥调度中枢：串接 8 位家人 + RAG + A2A，形成「安全→路由→检索→并行执行→润色→汇总→质检→审计→个性化」九步闭环。

## 二、九步时序表（核心规范）

| 步 | 执行者 | 动作 | 关键规范 |
| -- | ------ | ---- | -------- |
| 1 | 智云·守护 | 输入安全三级过滤 | L1注入/L2 PII/L3合规；拦截即终止 |
| 2 | 言启·千行 | 意图识别与任务路由 | <200ms；trace_id 生成 |
| 3 | 公共RAG | 知识检索与上下文注入 | min_score≥0.6；`[来源：]`格式 |
| 4 | 语枢+预见 | 数据分析+趋势预测并行 | 双引擎并行（Collaborating） |
| 5 | 创想·灵韵 | 报告润色+可视化建议 | 风格×受众参数化 |
| 6 | 元启·天枢 | 全局汇总与决策升华 | 逻辑一致性校验 |
| 7 | 格物·宗师 | 质量校验与事实核查 | ≥80分通过；不达标触发 Step5 二次优化 |
| 8 | 智云·守护 | 输出审计与脱敏 | PII 脱敏；不通过阻断 |
| 9 | 知遇·伯乐 | 画像更新与个性化补充 | user_id≠default_user 才触发 |

## 三、五维五高五标五化对齐

| 维度 | 对齐项 |
| ---- | ------ |
| 五高-高可用 | 任一环节异常降级：RAG失败直答/LLM失败Mock/质检超时放行并标记 |
| 五高-高性能 | Step4 并行执行、场景分支A-F按需裁剪链路 |
| 五高-高安全 | Step1/Step8 双端安检闭环（零信任） |
| 五高-高智能 | 质检二次优化自动闭环 + 个性化画像反哺 |
| 五标-自动化 | execute 全流程自动编排，无人工干预 |
| 五标-可视化 | trace_id 串联九步，全程状态可查 |
| 五化-流程化 | 九步标准流程固化，场景模板化（A-F） |

## 四、场景分支标准

| 场景 | 链路裁剪 |
| ---- | -------- |
| A 综合报告 | 九步全开 |
| B 简单分析 | 裁剪 5/6，直出 |
| C 纯创作 | 4 只走创想 |
| D 恶意输入 | Step1 拦截即返 |
| E 匿名请求 | Step9 跳过 |
| F 预测专项 | 4 只走预见 |

## 五、接口规范

| 方法 | 签名 | 说明 |
| ---- | ---- | ---- |
| `execute` | `(user_input, user_id="default_user", scene=None) -> dict` | 九步闭环主入口，返回各步产出+trace_id |
| A2A 模式 | `AsyncOrchestrator.submit_multi_agent_task` | 异步多 Agent 并行编排（见 91 目录） |

详细参数表、错误码与四场景调用示例（综合报告/恶意拦截/简单分析/脱敏输出）见 [API.md](API.md)。

## 六、协同关系

- **总装成员**：8 位家人全量编排；RAG/A2A 双公共能力支撑
- **硬件底座**：双 DGX Spark（GB10/128GB 统一内存/200Gbps RoCE 直连 GPUDirect RDMA）+ NAS 双 RAID
- **映射定位**：流程化/服务化/生态化总集成点，「五高五标五化」全体系落地点

## 七、典型场景

- 董事长晨报：一句「出本月综合经营报告」→ 九步全链路 → 脱敏报告
- 恶意输入：越狱语句 → Step1 秒级拦截 → 审计留痕
- 匿名快速分析：无画像诉求 → 裁剪链路 → 秒级响应

## 八、AI 漫剧生产场景化对齐（YYC3-03）

漫剧六大阶段 = 本引擎九步闭环的场景化裁剪复用：

| 漫剧阶段 | 参与成员 | 九步映射 |
| -------- | -------- | -------- |
| 阶段1 创意立项 | 创想+格物+元启 | Step1/2/3 + decide |
| 阶段2 剧本分镜 | 语枢+智云 | Step3/4（语枢） |
| 阶段3 生产调度 | 元启+言启 | Step2/6 + plan_tasks |
| 阶段4 视听生成 | 创想+智云 | Step5 + Step7（质检重绘闭环） |
| 阶段5 合成交付 | 元启+创想 | Step6 + Step8 |
| 阶段6 运营闭环 | 预见+知遇+反哺 | Step4（预见）+ Step9 + 资产沉淀 |

| 对齐项 | 内容 |
| ------ | ---- |
| 漫剧专属定位 | 漫剧编排层核心：替代任务队列式调度，升级为多智能体自主协同调度 |
| 漫剧调用示例 | `orchestrator.execute(user_input="根据《凤临天下》小说第1卷生成分镜并批量出片", user_id="studio_01", scene="A")` → 九步全链路 → 成片归档 NAS 成品区 |
