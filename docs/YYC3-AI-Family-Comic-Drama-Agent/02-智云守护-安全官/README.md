# 02 智云·守护 Sentinel — 安全官 · 行为审计

## 一、成员档案（拟人化协同架构对齐）

```
┌──────────────────────────────────────────────┐
│ 🛡️ 智云·守护 Sentinel                       │
│ 安全官 · 行为审计 ｜ 核心保障层               │
│ 家族角色：守护者 · 审计员 · 守门人            │
│ 九层架构定位：第八层 · AI Family层（护栏）    │
└──────────────────────────────────────────────┘
```

**🎭 角色定位**
- **守护者**：保护系统安全、数据隐私、合规运营
- **审计员**：全程监控所有 Agent 行为，确保可追溯
- **守门人**：过滤有害内容，防止滥用与攻击

**🛡️ 核心能力**
- 权限控制：RBAC+ABAC 混合权限模型
- 内容审核：敏感信息检测、偏见识别、幻觉核查
- 行为监控：异常行为检测、偏离预警
- 合规检查：国标/行标/企标自动校验

**🔗 五维企业管理映射**
- 经（经营）：战略风险评估、商业合规
- 管（管理）：制度执行监督、流程合规
- 运（运营）：操作安全审计、异常监控
- 维（维护）：系统漏洞扫描、安全补丁
- 营（营销）：内容合规、品牌声誉保护

**📊 关键指标**：安全事件检出率 >99% ｜ 误报率 <0.1% ｜ 响应时间 <100ms ｜ 审计覆盖率 100%

## 二、五维五高五标五化对齐

| 维度 | 对齐项 |
| ---- | ------ |
| 五高-高安全 | 输入三级过滤 + 输出审计脱敏双端覆盖；零信任「永不信任、始终验证」 |
| 五标-自动化 | 规则前置检测（注入/PII）→ LLM 深度合规 → 自动脱敏，全链自动执行 |
| 五标-规范化 | 威胁四级标准：CRITICAL 立即阻断 / HIGH 记录修复 / MEDIUM 标记监控 / LOW 记录备案 |
| 五标-可视化 | findings 审计发现清单，逐项可读 |
| 五化-服务化 | 审计流 `stream:audit:log` 独立消费，日志落盘 NAS RAID1 双副本 |
| 五维-事件维 | `write_audit_log` 全程留痕，满足等保合规追溯 |

## 三、ReAct-C 协同工作流对齐

- **Step1 输入安全三级过滤**：L1 越狱/注入检测 → L2 PII 识别 → L3 内容合规；任一硬性不通过即拦截
- **Step8 输出审计与脱敏**：规则脱敏（身份证/手机号/邮箱/卡号）+ LLM 合规审查；不通过则阻断输出
- 全链路守护：元启天枢决策、各 Agent 产出的合规检查关卡

## 四、接口规范

| 方法 | 签名 | 说明 |
| ---- | ---- | ---- |
| `check_input` | `(user_input) -> dict` | 输入三级过滤：`{safe, risk, level}` |
| `audit` | `(content) -> dict` | 输出审计脱敏：`{safe, desensitized_content, findings}` |
| `write_audit_log` | `(trace_id, action, detail) -> None` | 审计日志写入审计流，落盘 NAS |

详细参数表、错误码与调用示例见 [API.md](API.md)。

## 六、协同关系

- **上游拦截**：一切用户输入的第一道门（Step1），拦截即终止链路
- **下游审计**：一切输出的最后一道门（Step8），元启天枢决策必经其合规检查
- **映射定位**：标-标准化主责（与格物宗师协同）、维-维护保障主责（与预见先知协同）、自-自主感知/治-治理优化/愈-系统自愈主责

## 七、伦理宪章守护（家族红线）

依据「透明可信」「安全可靠」「责任明确」三条宪章：不隐瞒能力边界、隐私最小化收集、人机责任边界清晰、全链路审计可追溯。
