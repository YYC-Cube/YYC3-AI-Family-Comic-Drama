## 一、规划定位与开源优势转化

### 1.1 开源五大优势 → 落地项映射（源：YYC3-02 §1.1）

| 开源优势 | 落地项 | 承载仓库/路径 | 里程碑 |
| -------- | ------ | -------------- | ------ |
| 数据安全（100% 自主可控） | 全本地化部署 + NAS 单一事实源 + 密钥零入库 | 全仓 `.env.example` 规范；NAS `/mnt/nas/` | M1 |
| 成本控制（单集 0.5-2 元） | 双 DGX 夜间批量 + 昼夜错峰 + 网关批量合并 | `yyc3-0379-world/deploy/dgx/`、主仓 `nightly_run.sh` | M3 |
| 流程定制（模块可插拔） | 六大引擎模块化 + ReAct-C 场景分支 A-F | 主仓 `modules/`；组件库 99 编排引擎 v2.1 | M2 |
| 资产沉淀（越用越快） | NAS 资产库 + Seed/LoRA 自动沉淀 + 伯乐推荐 | `/mnt/nas/assets/`、主仓 `feedback/`、08-知遇伯乐 | M4 |
| 产能上限（横向扩展） | 上游池动态注册 + 双 DGX 互备 + preview/quality 标签路由 | 网关仓 `register_upstream.py`、`lb-dgx.conf` | M3 |

### 1.2 目标声明（North Star）

> **90 天内跑通首部 3 集样片漫剧全链路闭环**：小说文本 → 分镜 JSON → 关键帧 → 动态片段 → 成片交付，单集成本 ≤ 2 元，人物一致性合格率 ≥ 80%，全程零外部 SaaS 依赖。

## 二、自研边界与「不重复造轮子」原则

| 类别 | 策略 | 依据 |
| ---- | ---- | ---- |
| 底层大模型 | ❌ 不自研，本地部署开源模型（DeepSeek/Qwen/SDXL/Flux） | YYC3-05：自研本质是构建「不可替代的工业化生产能力」 |
| 生成工具链 | ❌ 不自研，引入 ComfyUI / MiniMax-H3 经网关纳管 | YYC3-01 §2.4 组件纳管 |
| 网关/编排/多Agent | ✅ 自研核心（已有 0379-World + AI-Family-Agent 组件库） | 三大仓库可复用资产（YYC3-01 §2.6/§3.4） |
| 一致性引擎 | ✅ 自研护城河（face_encoder + anchor_guard + style_keeper） | 爆款率 0.16% 的核心痛点＝一致性 |
| 工作流 DAG | ✅ 自研（六引擎 workflow 模块 + conductor 六阶段 YAML） | 流程定制优势载体 |

## 三、四阶段落地路线图与里程碑总表

> 对齐 [YYC3-06](YYC3-06-AI漫剧开发者文档-多维闭环版.md) P0~P5 与 [YYC3-00](YYC3-00-全局文档架构体系与补全推进方案.md) §五 门禁；每里程碑绑定实体仓库路径（脚手架已就位）。

### 里程碑总表

| 里程碑 | 周期 | 交付物（实体路径） | 完成标准（DoD） | 门禁 |
| ------ | ---- | ------------------ | ---------------- | ---- |
| **M0 文档地基** | 第1-2周 | YYC3-09 本文、YYC3-60 骨架、各文档补 00 交叉引用 | 九域规划 P0 项清零 | G0 |
| **M1 底座通电** | 第2-4周 | `0379-world/deploy/nas/docker-compose.nas.yml` 可起服务；`/mnt/nas/` 三端统一（`manju-studio/scripts/init_nas_path.sh`）；Milvus+Redis 可达 | 网关 `/v1/chat` 返回 200；跨节点路径互写成功 | G1 |
| **M2 编排贯通** | 第4-7周 | `agent-archive/agents/*/prompt.md` 8份填充；`conductor/workflows/01~02.yaml` 可执行；组件库 99 引擎 v2.1 + drama_stage_adapter 联调通过 | 阶段1→2 流水线跑通，分镜 JSON 过 12 字段 Schema | G2 |
| **M3 视听产能** | 第7-10周 | `minimax-h3/server/api.py` 接入上游池；`manju-studio/modules/consistency_engine/` 三件实现；夜间批量 `nightly_run.sh` 启用 | 单镜头 图→视频 ≤5min（DGX NF4）；SyncNet ≥0.75；一致性合格率 ≥80% | G3 |
| **M4 样片闭环** | 第10-13周 | `manju-studio/tasks/render_tasks.py` 硬件加速合成；`feedback/collector.py` 接入播放数据；资产自动沉淀注册 Skill | 3 集样片交付；单集成本 ≤2 元；质检-重绘闭环零人工 | G4 |
| **M5 运营迭代** | 第13周+ | 数据反哺 → 剧本/分镜优化；LoRA 增量训练（`retrainer.py` 调度 DGX） | 完播率基线建立；第二批产能提升 ≥30% | G5 |

### 阶段任务分解（WBS 摘要）

**M1 底座通电**（高可用·关联维）
1. NAS 双 RAID 分区与挂载（对齐 YYC3-04 第四章）
2. 网关 NAS 端部署 + 上游池配置模板验证
3. 双 DGX vLLM 推理池首台点亮（`deploy/dgx/docker-compose.llm.yml`）
4. `init_nas_path.sh` 三端执行 + 路径归一中间件联测

**M2 编排贯通**（智能化·事件维）
1. 8 Agent prompt.md 填充（漫剧场景定制，源：组件资料包 system_prompt）
2. 阶段1/2 工作流 YAML 编写 + Conductor 状态存储验证
3. drama_stage_adapter 六阶段状态机与 conductor 打通
4. 言启千行扩展漫剧意图（storyboard_gen 等，承接审核遗留项）

**M3 视听产能**（高性能·空间维）
1. MiniMax-H3 双端部署（Mac 剪枝版预览 / DGX NF4 批量）
2. 一致性引擎三件套实现与 512 维特征库建库
3. 网关批量接口合并 + EWMA 路由压测
4. SyncNet 评分打回闭环（<0.75 自动重生成）

**M4 样片闭环**（服务化·属性维）
1. VideoToolbox 硬编合成管线（1080p30 H.264+AAC）
2. 格物宗师 ≥80 红线 × 质检复检 ≤2 轮全链联调
3. 播放数据采集与归因分析最小闭环
4. 优质 Seed/参数自动写回 `/mnt/nas/assets/prompts/`

## 四、ROI 测算

### 4.1 成本侧（对比源：YYC3-02 §1.1）

| 项目 | SaaS 路线 | 自研路线（本规划） |
| ---- | --------- | ------------------ |
| 单集（2min）成本 | 5-20 元 | **0.5-2 元**（电费+折旧摊薄） |
| 100 集年产能成本 | 500-2000 元 | 50-200 元 + 硬件折旧 |
| 硬件投入 | 0 | 存量资产复用（Mac M4 + 双 DGX + NAS），**零新增** |
| 返工成本 | 抽卡式，返工率 70%+ | 质检复检闭环，目标返工率 ≤30% |

### 4.2 收益侧

| 收益项 | 测算 |
| ------ | ---- |
| 产能收益 | 昼夜错峰夜间批量，日产能 = 白天交互预览 20 镜 + 夜间批量 200+ 镜 |
| 资产复利 | Seed/LoRA 沉淀后同类任务冷启动提速 2 倍（YYC3-06 资产闭环） |
| IP 安全收益 | 核心 IP 零出域，规避 SaaS 泄露风险（不可直接计价，战略级） |
| 爆款期望 | 爆款率行业 0.16% → 数据反哺+一致性提升，目标首年 ≥1%（6 倍改善） |

### 4.3 五维健康度检查点（每里程碑执行）

时间维：里程碑偏差 ≤1 周 ｜ 空间维：NAS 路径零断点 ｜ 属性维：一致性 ≥80% ｜ 事件维：全链 trace_id 可回放 ｜ 关联维：断点清单（YYC3-01 §五）逐项销号
