## 一、TC-G4-001 单镜音视频合成管线（PASS ×2）

**前置变更**：[run_clip_compose.sh](../scripts/run_clip_compose.sh) 升级交付规格——`-r 30` + `scale=1920:1080:force_original_aspect_ratio=increase,crop=1920:1080`（方形原图 1024x1024 等比覆盖后居中裁切，避免拉伸变形）。

**留证**（两次执行）：

| 字段 | run1 | run2 |
| ---- | ---- | ---- |
| codec | h264 | h264 |
| 分辨率 | 1920x1080 | 1920x1080 |
| 帧率 | 30/1 | 30/1 |
| 音频 | aac 128k | aac 128k |
| 时长 | 2.148s | 2.194s |

音画时长偏差：`-shortest` 保证视频轨贴合音轨，偏差 ≤1 帧。时长差异（46ms）源于 piper TTS 字节级非确定性（94764 vs 96812 bytes），属预期波动，规格字段两次完全一致 → **PASS**。

## 二、TC-G4-003 集级串联成片（PASS）

**方法论沉淀（三轮实测定版）**：

| 方法 | 时长偏差 | 判定 |
| ---- | ---- | ---- |
| ✗ 流拷贝 `-c copy` | +47ms（1.4 帧） | 超容差 |
| ✗ 视频拷贝 + 音频重编 | +70ms | 超容差 |
| ✓ 全重编码单时间线 | **+20.3ms（0.6 帧）** | **PASS** |

**根因**：每文件 AAC 码流自带 priming 样本，流拼接逐文件累积；全重编码收敛为单时间线帧对齐。已沉淀为 [run_episode_concat.sh](../scripts/run_episode_concat.sh)（自动验证：视频轨时长 ±1 帧 / 黑帧检测 / 规格回显）。

**规格修订**（YYC3-60 v1.3.1 同步）：±1 帧判定基准 = **视频轨时长**（格式时长含 AAC padding，为编码器物理产物非内容偏差）。

**留证**：c1(4.981s)+c2(2.194s)+c3(3.738s)=10.913s → 成片视频轨 10.933s；黑帧 0；顺序 c1→c2→c3 与 storyboard.v1 一致。

**判定说明**：门禁口径 = [run_syncnet_score.py](../scripts/run_syncnet_score.py) `conf ≥0.75 达标`。conf 6.3167 大幅超限，物理根因：Ref2VA 为音视频**联合生成**，口型与生成语音由同一模型内生同步（区别于 G4-004 静态帧 + 外挂 TTS 后配音的错位模式）。offset 0.0 无音画偏移。

**诚实留证**：dist=11.654 偏高（SyncNet 距离值，越低越好，经验良好带 <8），conf 判定与 dist 观察存在张力，推测与 384p preview 档分辨率下唇部细节量有关；后续 720p 档复验时跟踪。另：本用例直跑执行器完成（网关 :8300 claim_ready:true 已验证；网关复跑全链留证列为可选后续）。
