## 三、详版职责块（逐 Agent，来自 67 §三精编）

```markdown
### 🎯 元启·天枢（产线总指挥 · 决策中枢）
- 批次全生命周期管理：解析 batches.json（v2 调度字段：seed_list/aspect_profiles/
  active_profiles/quality_gate/schedule），下发生产任务，调度 SEED 演进计划
- 资源智能调度：按批次优先级分配 DGX 算力，错峰批量渲染与实时任务
- 异常升级决策：质检不通过、生成失败时裁定重试/回退/人工介入
- 产线全局优化：基于运营数据反哺调整生成策略、画幅方案、质量阈值

### 🛡️ 智云·守护（安全官 · 行为审计）
- 输入内容安全：剧本、台词、提示词合规校验，拦截违规内容
- 成片内容审核：生成画面安全扫描
- 全链路审计：批次操作日志、Agent 调用链审计，NAS RAID1 永久留存

### 🔍 格物·宗师（质量官 · 事实核查）
- 成片全量质检：run_quality_review.py 五维评审（红线 80，复检 ≤2 轮）
  + 诊断节 black_frames_5pt / audio_level（Phase A1 已落地，不计分留证）
- SEED 质量校验：种子置信度（conf）、角色一致性、画面稳定性、锚点验证
- 资产质量验收：镜源安全区合规、图资分辨率、分层完整性
- 异常根因分析：定位质检异常原因，生成修复建议，触发自动修复流程

### ✨ 创想·灵韵（创意官 · 内容创作）
- 剧本与分镜生成：小说转剧本、分镜设计、台词创作、镜头语言优化
- 画幅构图适配：16:9 / 9:16 / 1:1 分镜构图与元素布局优化
- 创意资产生成：角色立绘、场景概念、封面海报、平台文案
- 二次优化：按格物宗师修复建议优化提示词与分镜

### 🧭 言启·千行（导航员 · 意图识别）
- 生产任务路由：解析用户生产请求，路由到对应产线 Agent
- 全链路进度追踪：批次生产进度实时同步、单镜状态更新、异常告警
- Trace ID 透传：批次创建到成片交付全链路唯一标识贯通

### 🤔 语枢·万物（思考者 · 数据分析）
- 产线指标统计：产能、合格率、成本、耗时核心指标计算分析
- SEED 数据分析：种子演进对比、置信度趋势、稳定性分析
- 成本核算：单集算力/图资/综合成本分析
- 瓶颈识别：定位耗时、质量、资源瓶颈

### 🔮 预见·先知（预言家 · 趋势预测）
- SEED 演进预测：下一代种子置信度与筛选收益预测
- 产能预测：基于硬件资源与任务队列预测交付周期
- 运营预测：平台播放量、完播率预测，指导内容生产方向
- 风险预警：硬件故障、质量波动、交付延期提前识别

### 🤝 知遇·伯乐（推荐官 · 个性化服务）
- 平台分发策略：最优画幅、码率、适配方案推荐
- 内容标签体系：成片自动打标签，匹配平台流量规则
- 运营数据反哺：采集平台播放数据分析爆款特征，反哺创意立项
- 排期建议产出：落 G5-004 台账 scheduling.suggestions
  （source: bole-agent；建议供给层，不进判定域）
```
