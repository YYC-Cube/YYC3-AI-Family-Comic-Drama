## 三、三方评分对账与差异根因

### 3.1 对账表

| 评分来源 | 分值 | 判定 | 覆盖域 |
| -------- | ---- | ---- | ------ |

| 外部深度评测（本报告） | **37 / 不达门槛** | 打回 | 关键帧层 + **视频层**（一致性/动效/结构）+ 音频听感 |

### 3.2 根因：门禁覆盖域盲区（8 项）

以 [run_quality_review.py](file:///Users/yanyu/YYC-Cube/YYC3%20AI%20Family-Comic%20Drama/scripts/run_quality_review.py) 代码为基（L60 音频码率专用、L142-144 manifest 仅打元数据存在分）：

| # | 盲区 | 后果 |
| - | ---- | ---- |
| B1 | **未仲裁 `gate_critique`**——revise/57.9 与 95/PASS 并存，以宽松者放行 | 两套门禁打架无聚合裁决 |
| B2 | 无冻结检测（freezedetect） | 10.2s「静图挂屏」判为正常 |
| B3 | 无段级一致性校验（镜头段 vs 已验收源帧） | 镜 3 换画面（SSIM 0.24）无人拦截；SDXL 阶段2 身份保持 0.9029 成绩只覆盖关键帧层，**视频层一致性裸奔** |
| B4 | 无镜间多样性检查 | 三关键帧同质（两两 SSIM 0.72）无人拦截 |
| B5 | 无视频码率维度（仅音频码率） | 789kbps 色带风险放行 |
| B6 | 无 silencedetect | 三段静音空洞 1.27s 放行 |
| B7 | 无 VFR/帧率口径检查（时长判定容差内即过） | 29.774fps 带病放行 |
| B8 | 无 storyboard 对账（planned vs produced 完成度 / 占位镜检测） | 80 镜规划 vs 3 镜实产、54 镜占位、尾钩子占位均无告警 |

> **结论**：95 是「容器体检分」，37 是「内容体检分」。两者不矛盾，差异全部来自覆盖域。旧质检在其覆盖域内无错判，但**放行权限超出了其覆盖域**——这是产线级门禁设计缺陷，不是单次执行失误。

## 四、审核决议

1. **采纳**外部深度评测报告全部结论与修复优先级建议（P0 三项：prompt 模板重构 / 动画面段首帧约束 / duration 与运镜真正驱动渲染）。
2. **两处口径补充**：静音空洞为三段合计 ≈1.27s（报告列一段）；v916 码率 525k 为容器口径（视频流 396k）。
3. **一项补充发现入整改**：横版母版 `_full.mp4` 未吃到 concat 修复（S1），全批六集同状态；分发前须以修复后流程重渲横版终稿。
4. **升级一项为 P0**（报告 P1 中的占位镜清理 + 我方 B1）：门禁聚合仲裁 + storyboard 占位镜治理提前至 P0（B1/B8 是「带病放行」的制度性根因）。
5. **波及面判定**：006 的三层断裂为**管线性缺陷**（同一 storyboard 生成器 + 同一 compose 链产出），推定全批六集同源同病；整改后全批重产复评，非 006 单集返工。
