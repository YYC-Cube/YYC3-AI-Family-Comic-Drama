### 1.3 体系设计五原则（五标对齐）

| 原则 | 落地要求 |
| ---- | -------- |
| 标准化 | 编号唯一（YYC3-00~99），frontmatter 必填（version/updated/related_docs），家族标头标尾印记 |
| 规范化 | 一文档一事实源；跨文档引用用相对链接；数据指标须可溯源到源文档章节 |
| 自动化 | 文档变更触发校验脚本（编号/链接/命名一致性 grep 审计） |
| 可视化 | 每份文档带「核心理念」四件套 + 徽章栏 + Mermaid/ASCII 架构图 |
| 智能化 | 文档体系与 Agent 组件联动：03 的对齐说明由组件库 README 自动映射生成 |
