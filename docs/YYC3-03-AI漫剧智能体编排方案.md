## 一、与现有漫剧系统的可衔接性分析

YYC³ 的核心定位是企业级多智能体编排与技能资产平台，恰好补全现有系统「编排层智能化、资产标准化、流程自优化」的短板，属于增强式衔接，平滑叠加能力。

### 1.1 架构层：天然适配现有五层架构

漫剧系统分为「接入层-编排层-模型层-资产层-渲染层」，YYC³ 可直接嵌入编排层，将原来的「任务队列式调度」升级为「多智能体自主协同调度」，各层通过标准 API 互通，无架构冲突。

| 现有架构层级 | YYC³ 对应能力 | 衔接方式 | 价值提升 |
| ------------ | ------------- | -------- | -------- |
| 接入层（前端工作台） | workflow-builder 可视化工作流构建器 | 嵌入 React 前端，替代固定流程配置 | 支持拖拽式调整生产流程，无需改代码 |
| 编排层（任务调度） | conductor 协同编排引擎 + orchestrator 智能调度器 + 8 大 Agent | 替代原有 Celery 固定 DAG，升级为多智能体驱动 | 从"人工配流程"变为"Agent 自主排产、自主优化" |
| 模型层（DGX 算力） | mcp-runtime 统一 MCP 运行时 + skill-gateway API 网关 | 将 DGX 上的 LLM、文生图、生视频等模型封装为 MCP 工具/标准 Skill | 模型能力标准化，Agent 按需调用，无需硬编码接口 |
| 资产层（NAS 存储） | skill-registry 统一技能注册中心 | 将 NAS 中的 LoRA、素材、模板、音色封装为可复用资产 Skill | 资产标签化、版本化、可检索，复用效率提升 60%+ |
| 渲染层（Mac 合成） | skill-sandbox 沙箱执行环境 | 将 FFmpeg 合成、字幕渲染封装为自动化 Skill | 合成任务自动触发，无需人工介入 |

### 1.2 技术栈：完全兼容无冲突

- **接口兼容**：现有后端是 Python FastAPI，YYC³ 提供 REST 格式的 Skill Gateway，通过 HTTP 即可互通，支持异步任务回调，适配现有生成任务的状态追踪模式
- **部署兼容**：
  - YYC³ 核心调度服务（Node.js 生态）可直接部署在 Mac M4 上，利用统一内存跑轻量 Agent 逻辑，重算力任务仍调度到 DGX，符合「算力专责专用」设计原则
  - 双方均支持 Docker 容器化，可纳入现有 docker-compose 统一编排，和 DGX 的模型服务同管
- **前端兼容**：现有 React 前端可直接集成 YYC³ 的 workflow-builder 组件，或通过 iframe 嵌入工作流配置页面，无需重构前端
- **数据兼容**：NAS 统一挂载路径不变，YYC³ 的 Skill 直接通过本地路径读写资产文件，无需数据迁移

### 1.3 能力层：精准补齐核心短板

现有系统强在算力执行、生成链路、硬件效率，弱在智能决策、流程自治、质量闭环、资产沉淀；YYC³ 恰好补足这部分能力，形成「硬件算力 + 智能编排」的双核心：

| 补齐能力 | 说明 |
| -------- | ---- |
| 多智能体协同 | 从单一流水线变为 8 个 Agent 分工协作，覆盖创意、生产、质检、运营、优化全环节 |
| 技能资产化 | 所有生产工具、素材、模板、模型都变成可注册、可版本、可复用的标准化 Skill |
| 质量门禁 | 内置 Doctor 四检聚合质量门禁，可对接漫剧的画面质检、内容合规、人物一致性校验 |
| 数据闭环 | Agent 自动采集运营数据、分析效果、反哺生产流程，实现真正的自优化闭环 |

### 1.4 衔接风险与注意点

| 风险点 | 应对策略 |
| ------ | -------- |
| 技术栈差异（YYC³ 为 TypeScript，现有为 Python 栈） | 通过 API 层解耦即可，无深度耦合需求 |
| 8 个 Agent 原生为通用场景设计 | 针对漫剧生产做角色 prompt 定制 + 专属 Skill 绑定，才能发挥最大价值 |
| 双 DGX 算力负载均衡策略 | 通过元启·天枢 Agent 对接现有算力监控数据，做智能调度 |

## 三、全链路 Agent 协同流转流程

按照漫剧生产闭环，8 个 Agent 分阶段协同，人工仅在关键节点做确认，实现 90% 以上流程自动化。

### 3.1 协同流转总览

```
阶段1 创意立项 ──→ 阶段2 剧本分镜 ──→ 阶段3 生产调度
（创想+格物+元启）   （语枢+智云）      （元启+言启）
                                              ↓
阶段6 运营闭环 ←── 阶段5 合成交付 ←── 阶段4 视听生成
（预见+知遇+反哺）   （元启+创想）     （创想+智云）
```

### 3.2 阶段详解

#### 阶段 1：创意立项（创想 + 格物 + 元启 协同）

- **输入**：小说原文、创意关键词、IP 要求
- **流转**：
  1. 格物·宗师输出对应题材的创作规范与行业最佳实践
  2. 创想·灵韵输出人设方案、画风定义、世界观设定
  3. 元启·天枢评估技术可行性、算力成本，输出生产排期
- **输出**：立项确认书、资产需求清单、生产排期计划
- **人工介入**：仅需确认最终创意方向

#### 阶段 2：剧本分镜生产（语枢 + 智云 协同）

- **输入**：立项确认的原始文本
- **流转**：
  1. 语枢·万物自动完成文本清洗、剧情拆解、分集规划、分镜生成、提示词输出
  2. 智云·守护同步做内容合规初审 + 剧情逻辑校验，不合格自动打回修正
  3. 输出标准化分镜 JSON，自动同步到 NAS 项目目录
- **输出**：结构化分镜表、配音文案、提示词清单
- **人工介入**：可选择性微调分镜节奏与台词

#### 阶段 3：生产调度（元启 + 言启 协同）

- **输入**：确认后的分镜任务
- **流转**：
  1. 元启·天枢根据项目优先级，分配双 DGX 算力资源，编排生产流水线
  2. 言启·千行负责工具链适配，批量提交生成任务，处理异常报错
  3. 任务自动进入 DGX 队列，状态实时同步到前端
- **输出**：生成任务工单、算力分配方案
- **人工介入**：无需干预，异常告警时人工介入

#### 阶段 4：视觉与音频生成（创想 + 智云 协同）

- **输入**：分镜生成任务
- **流转**：
  1. 创想·灵韵调用文生图 Skill，批量生成关键帧，自动加载对应角色 LoRA
  2. 智云·守护逐帧做人物一致性校验 + 画面崩坏检测，不合格自动重绘
  3. 图生视频、TTS 配音、口型对齐自动串行执行
- **输出**：单镜头音视频片段、质检报告
- **人工介入**：抽检关键镜头效果，可局部返工

#### 阶段 5：后期合成交付（元启 + 创想 协同）

- **输入**：合格镜头片段
- **流转**：
  1. 元启·天枢调度 Mac 端的合成 Skill，自动完成片段拼接、转场、字幕渲染、音画合成
  2. 创想·灵韵做最终效果验收，确认整体风格与节奏
  3. 成片自动归档到 NAS 成品区
- **输出**：最终成片、封面图、发布素材包
- **人工介入**：最终成片审核确认

#### 阶段 6：运营与闭环优化（预见 + 知遇 + 全链路反哺）

- **输入**：成片发布后的运营数据
- **流转**：
  1. 预见·先知自动采集多平台播放数据，生成效果分析报告，输出剧情、节奏、画风优化建议
  2. 知遇·伯乐统计产能与交付效率，输出生产流程优化点
  3. 优化建议自动反哺语枢·万物（剧本）、创想·灵韵（视觉）、元启·天枢（流程）
  4. 优质素材、模板、LoRA 自动沉淀到 NAS 资产库，注册为新 Skill
- **输出**：优化报告、资产沉淀清单、下一期迭代方案
- **人工介入**：确认优化方向与优先级

## 四、落地衔接实施步骤

### 第一步：能力封装（1-2 周）

将现有漫剧系统的核心能力接入 YYC³ 体系：

| 封装对象 | 动作 |
| -------- | ---- |
| 模型能力 MCP 化 | 通过 mcp-runtime 将 DGX 上的 LLM、SDXL、AnimateDiff、TTS、质检接口封装为标准 MCP 工具，配置权限与限流 |
| 生产节点 Skill 化 | 将剧本拆解、分镜生成、批量生图、视频合成等流程节点封装为标准化 Skill，注册到 skill-registry，绑定输入输出 Schema |
| 资产 Skill 化 | 将 NAS 中的角色 LoRA、场景素材、分镜模板、配音音色封装为资产型 Skill，打标签分类，支持检索调用 |

### 第二步：编排部署（2-3 周）

1. 在 Mac M4 上部署 YYC³ 核心服务（Skill Gateway、Conductor、Agent Runtime、Orchestrator），配置 NAS 挂载路径与 DGX API 地址
2. 针对漫剧场景定制 8 个 Agent 的系统 prompt，绑定对应的 Skill 与 MCP 工具，明确职责边界
3. 通过 workflow-builder 配置漫剧全链路工作流，设置各节点的触发条件、质检规则、异常处理策略

### 第三步：联调跑通（1 周）

- **单集全流程端到端测试**：验证从剧本输入到成片输出的 Agent 协同链路
- **双 DGX 调度测试**：验证元启·天枢的算力分配与负载均衡逻辑
- **质量闭环测试**：验证智云·守护的质检规则与自动重绘流程

### 第四步：迭代优化（持续）

- 沉淀生产数据，微调 Agent 的决策逻辑与提示词效果
- 持续新增专属 Skill，扩展生产能力
- 接入更多运营数据，优化预见·先知的分析准确度
