# 开源对标功能演进审核：AI 漫剧/短剧生成（MiraFrame/OnlyShot 及同类）

## 一、调研口径与核实结论

**核实通道**：GitHub REST API（仓库元数据）+ raw README 全文。检索执行时间 2026-10-03。

### 1.1 MiraFrame（[Lsq128/MiraFrame](https://github.com/Lsq128/MiraFrame)）实态

| 项 | 核实值 |
| -- | ------ |
| 定位 | AI 漫剧创作全栈 Agent（学习/演示/原型，官方声明不建议直接生产） |
| 技术栈 | TS 全栈：React 18 + Nest.js 11 + LangGraph.js v1.x + PostgreSQL 16 + Redis/BullMQ + Socket.IO |
| 流程 | 故事大纲→角色设定→分镜脚本→角色图→镜头画面→视频素材→导出 |
| 工程亮点 | 三节点人工反馈闸门、失败态+重试、Fake Provider（零 Key 跑通全链）、WebSocket 进度推送、shared Zod Schema 防类型漂移 |
| 简报外新发现 | **CRITIQUE 自批判环**（CRITIQUE_ENABLED / CRITIQUE_SCORE_THRESHOLD / CRITIQUE_MAX_ROUNDS 环境变量，生成质量阈值化重roll）；TTS/BGM 配置位 |
| 元数据 | 71 star / 30 fork / TypeScript / MIT（README）；**pushed_at=2026-06-03（创建当日），维护停滞约 4 个月** |

### 1.2 OnlyShot（[A-cat-with-carrots/OnlyShot](https://github.com/A-cat-with-carrots/OnlyShot)）实态

| 项 | 核实值 |
| -- | ------ |
| 定位 | 工业级竖屏短剧 Claude Code Skill（红果/抖音向），v0.6.1 |
| 技术栈 | Python + Claude Code + 即梦 dreamina CLI（Seedance 2.0），纯本地文件化项目结构 |
| 流程 | Phase 0 市场情报 → Phase 1 创作（IP 简报/节奏地图 36 grid x 4-10s/红果必爆 7 招）→ Phase 1.5 分镜图层（每 grid 1-4 候选，人工选图，关键 grid 首尾帧）→ Phase 2 四模视频生成 → 剪辑 |
| 工程亮点 | 分镜图=视频首帧（修改成本 1/18）、4 模自动选择（按文件存在）、8 段 prompt SOP（<=1500 字）、视觉指纹分阶段隔离、ref 完备性预检、敏感词预检、17 失败模式手册 |
| 简报外新发现 | 分镜图阶段 `--no-fingerprint`（防 ref 风格词污染正片光效）、multimodal stuck 任务自动检测回捞、evals.json 18 条断言 |
| 元数据 | 302 star / 31 fork / Python / MIT / pushed_at=2026-07-07 |

### 1.3 核实差异声明（诚实留证）

- 用户简报称 MiraFrame "未深度对接商用视频模型"——与 README 一致；但简报未提 **CRITIQUE 自批判环**，本审核补充纳入。
- 用户简报列出的 BigBanana AI Director / Toonflow / ArcReel / ManjuForge / AIMangaStudio 五项**未逐一核实**（GitHub 检索未命中同名仓库，简报信息按转述口径对待，不作为采纳依据）。
- huobao-drama 经 API 核实：15,670 star（本赛道最高），Vue 主导，活跃（2026-10-02 仍有推送）；**license 字段为 Other/NOASSERTION，与简报 "MIT" 不符**，二次开发前须先审许可。

## 三、项目现状对标基线

本项目（YYC³ AI 漫剧）已闭环能力（详见 [YYC3-61 指导目录](YYC3-61-AI漫剧全链路闭环生产操作指导目录.md)）：

- 全链路：小说→剧本分镜（90s 窗口+钩子）→静态镜（ComfyUI+IPAdapter 双档位+LoRA v2 combo）→动态镜（H3 720p）→TTS→ffmpeg 合成→评分→留证归档
- 质量指标化：身份锚 mean>=0.85（insightface+参考系锚定）、SyncNet 唇同步、anchor_guard 拒收链
- 成本/产能：0.0168-0.0335 元/集、3 集/晚、Token-Console 计量
- 治理：G1-G5 门禁执行器、HANDOFF 37 轮、八项证伪台账、38 件脚本资产

## 四、适用性审核矩阵（核心）

判定口径：**采纳**（低成本高契合，E1 落位）/ **部分采纳**（需勘察或裁剪，E2）/ **不采纳**（技术栈冲突/成本倒挂/定位不符）。

| # | 对标功能 | 来源 | 项目现状 | 判定 | 落位要点 |
| - | -------- | ---- | -------- | ---- | -------- |
| A1 | 市场情报前置（Phase 0） | OnlyShot | 无题材层情报，直接小说输入 | **采纳** | run_market_scan.py：检索快照人工导入（不爬虫，合规红线）→ 市场情报 JSON → 剧本切集前输入 |
| A2 | 秒级节奏地图 + 爆点校准 | OnlyShot | 90s 窗口+章末钩子，无秒级节奏 | **采纳** | 分镜 schema 增 grid 秒级标注 + beat 类型（cold_open/twist/satisfaction/cliffhanger）；**红果 7 招节点基于 180s 集，本项目 90s 窗口须自行折算校准，禁止盲抄秒数**；增节奏分布校验脚本 |
| A3 | 分镜候选选帧闸门（Phase 1.5） | OnlyShot | 静态镜先行=构图前置已具备；seed 42/43/44 天然候选机制，但无系统化选帧 | **采纳** | run_storyboard_candidates.py：每镜 3-4 seed 候选 + anchor_guard 预打分排序 → 人工终选落 manifest；把「修改成本前置」从架构优势变成显式工作流 |
| A4 | 故障模式手册（17 失败模式） | OnlyShot | 37 轮 HANDOFF 教训散落各章 | **采纳（零成本）** | 从既有留证结构化提炼：ComfyUI 400 默认模型/HF 直连超时/384 图断言/缓存命中误判/参考系漂移/GB10 串行化/batch_size 移除/fp16 半量误判/1024 队列超时/Milvus 依赖桩 等 >= 11 条成册（61 号目录附录扩展或独立 64 号） |
| A5 | 敏感词预检 + AIGC 标识 | OnlyShot | 无敏感词扫描；AIGC 标识未入 manifest | **采纳（合规必配）** | 分镜 prompt 预检（反派词/暧昧词替换表移植）；成片 manifest 增 AIGC 标识字段（平台发布要求） |
| A6 | 自批判环（CRITIQUE 阈值重roll） | MiraFrame（新发现） | run_quality_review 在成片层；剧本/分镜层无自批判 | **采纳** | 分镜产出后 6 维度自批判（节奏/冲突/画面性/对白/钩子/一致性）+ 阈值不达触发局部重生成（CRITIQUE_MAX_ROUNDS 上限 2 轮防成本失控） |
| A7 | 全链 Fake 冒烟入口 | MiraFrame Fake Provider | stub 降级先例已有（HA fallback）；无一键全链 fake 预检 | **采纳** | 夜批前置预检：COMFYUI/H3/TTS 全 stub 模式跑通状态机（零 GPU 成本验证链路完整性），失败即阻断真实批次 |
| A8 | 工业级 Ref 库（80-150 张） | OnlyShot | hero_base 单图 + LoRA | **部分采纳（E2）** | 角色 5-8 张（动作/表情）+ 场景多角度分批建设；直接服务 anchor_guard 多参考评分与 H3 多参考输入；与 YYC3-62 基模迁移（Ref 库跨基模复用）联动规划 |
| A9 | 四模视频生成 | OnlyShot | H3 ref2va 单参考（约等于 image2video） | **部分采纳（E2 先勘察）** | 首尾帧模式对爆点镜头价值高，但 **H3 agent 网关是否支持 frames2video 待勘察，不盲承诺**；勘察后再定实验排期 |
| A10 | 可观测性（进度推送/节点详情） | MiraFrame | 夜批日志式观测 | **部分采纳（E2 轻量版）** | 夜批结构化 JSONL 进度事件落盘 + 网关（FastAPI 已有）暴露 /progress SSE；**不建全栈 Web 工作台**（单项目系列生产，避免过度工程） |
| A11 | Provider 统一抽象 + 连接测试 | MiraFrame | ComfyUI/H3/TTS/SyncNet 各自 client，无统一 test 口 | **部分采纳（E2 低优先）** | 冒烟入口统一化（comfy/gateway/tts/syncnet 四探针一键体检），复用 G1 三探针模式 |
| A12 | LangGraph 状态机/全栈重构 | MiraFrame | Python 脚本编排 + HANDOFF 协议已闭环 | **不采纳** | 技术栈冲突；状态机价值以轻量「流水线状态 JSON」（E2 可选）承接，不为架构而架构 |
| A13 | PostgreSQL/Redis/BullMQ 基建 | MiraFrame | manifest 文件化 + 夜批 3 集/晚 | **不采纳** | 当前规模文件化足够；引入消息队列属过度工程（规模 >10 集/晚再评估） |
| A14 | 即梦/Seedance API 出片 | OnlyShot | 自托管 ComfyUI+H3 | **不采纳** | 成本倒挂（自托管 0.0168-0.0335 元/集）；画质破局主线是基模迁移（YYC3-62），非外部 API 依赖 |
| A15 | Web 项目管理 UI | MiraFrame/huobao | HANDOFF+AskUserQuestion 人机协同 | **不采纳（E3 远期）** | 当前单操作者+AI 导师模式，UI 价值低；多角色协作需求出现后再评估 |

**审核总结**：采纳 6 + 部分采纳 5 + 不采纳 4。核心判断依据：本项目差异化壁垒在**指标化质量门禁与治理体系**（四对标项目均无），演进方向是补**内容运营层**（A1/A2/A6）与**工作流显性化**（A3/A4/A5/A7），而非重构已闭环的工程链路。

## 六、采纳项执行细则（E1 六件套，按轮次排布）

| 项 | 交付物 | 验收口径 | 留证 |
| -- | ------ | -------- | ---- |
| A1 市场情报 | scripts/run_market_scan.py + 情报 JSON schema | 情报字段（题材热度/衰退赛道/反同质化建议）完整且来源可溯 | 情报 JSON 入 attachments |
| A2 节奏地图 | 分镜 schema v2（grid 秒级 + beat）+ run_rhythm_check.py | 90s 窗口内爆点分布通过折算校验（校准公式入册） | 校验报告 JSON |
| A3 选帧闸门 | scripts/run_storyboard_candidates.py | 每镜 >=3 候选 + anchor_guard 预分排序 + 选定结果回写 manifest | 候选评分 JSON |
| A4 故障手册 | YYC3-64 故障模式手册（或 61 号附录） | >=11 条结构化条目（现象/根因/解法/预防） | 手册入库 |
| A5 合规预检 | 敏感词扫描函数 + manifest AIGC 字段 | 扫描命中即 warn 并给替换建议；成片 manifest 含标识字段 | 扫描日志 |
| A6/A7 | 自批判环 + Fake 全链冒烟 | 批判 6 维评分落盘；stub 预检全绿方放行夜批 | 批判/预检 JSON |

**排期建议**：E1 拆两轮——第一轮 A4（零成本成册）+ A5 + A7（治理加固）；第二轮 A1 + A2 + A3（内容运营）。E2 依赖勘察结论（A8 Ref 库随基模迁移联动；A9 待 H3 能力勘察；A10/A11 低优先穿插）。

## 七、风险与红线

- **合规**：市场情报仅用检索快照人工导入，不做平台爬虫（A1 红线）；AIGC 标识为发布必配（A5）。
- **成本**：自批判重roll 上限 2 轮（防 LLM 调用成本失控）；候选选帧仅增静态图生成（512px 低成本档），不触发视频层重生成。
- **盲抄风险**：红果 7 招节点秒数基于 180-195s 剧集实测，本项目 90s 窗口须按比例折算并自建校准基线（A2 最大误区点）。
- **许可**：huobao-drama 许可未明（NOASSERTION），参考其产品思路可以，**代码级借鉴前必须先澄清许可**；MiraFrame/OnlyShot 均 MIT 可安全参考。

2. **[P1]** E1 第二轮：A2 节奏地图 schema 与 90s 折算校准 + A3 候选选帧闸门（anchor_guard 预打分复用）
