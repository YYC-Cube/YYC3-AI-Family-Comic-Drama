### 1.2 落地基本原则

> **「不重复造轮子，自研护城河」** — 源自 [YYC3-05](YYC3-05-AI漫剧开源生态与自研路径.md)

| 类别 | 策略 | 判定依据 |
| ---- | ---- | -------- |
| 底层大模型 | 🟢 开源拉取 + 本地部署 | 自研大模型无性价比，DeepSeek/Qwen/Flux/MiniMax 已成熟 |
| 生成工具链 | 🟢 开源引入 + 网关纳管 | ComfyUI/MiniMax-H3/SyncNet 是行业标准实现 |
| 网关/编排/多Agent | 🔴 自研核心 | 已有 0379-World + AI-Family-Agent 组件库可复用资产 |
| 一致性引擎 | 🔴 自研护城河 | 爆款率 0.16% 的核心痛点 = 跨镜头一致性 |
| 工作流 DAG | 🔴 自研 | 流程定制优势的核心载体 |
| 基础设施组件 | 🟢 开源标准选型 | Milvus/Redis/PostgreSQL/Grafana 生态成熟 |

### 3.2 决策依据

**选开源的理由**：成熟度高、社区活跃、无差异化价值、避免重复造轮子。

**选自研的理由**：

1. 已有可复用资产（组件库 12 目录 + 0379-World 网关设计）
2. 是项目差异化护城河（一致性引擎直接决定爆款率）
3. 需要深度业务定制（漫剧六阶段工作流无通用方案）
4. 协议适配层必须自研（网关统一纳管异构上游）

## 六、自研模块设计要点

### 6.1 一致性引擎（自研护城河 · G3 核心）

```
face_encoder.py          → InsightFace/face_recognition 提取 512 维特征向量
                           存 NAS assets/characters/{id}/feature.npy
anchor_guard.py          → 生成前：加载角色特征向量锚定 prompt
                           生成中：ControlNet 姿态骨架约束
                           生成后：特征相似度校验 < 阈值自动重绘
style_keeper.py          → 风格种子 + 色彩配置（LUT）+ 笔触参数持久化
                           同角色跨镜头强制一致
```

**验收锚点**：人物一致性合格率 ≥80%（G3 门禁）

### 6.2 统一 AI 网关（自研核心 · G1 核心）

```
chat.py                 → OpenAI 兼容 /v1/chat/completions 代理
auth.py                 → X-API-Key + JWT 双鉴权
path_normalize.py       → Mac /Volumes/... → /mnt/nas/ 归一
adaptive.py             → EWMA（延迟+错误率+负载）自适应路由
circuit_breaker.py      → 3 败摘除 30s 半开熔断
```

### 6.3 六阶段工作流（自研核心 · G2 核心）

```
dag.py                  → 解析 conductor 01~06.yaml，校验依赖
state_machine.py        → pending → running → success/failed → rework
retry.py                → 失败重试（指数退避）+ 断点续传（NAS state/）
scheduler.py            → 优先级调度 + 昼夜错峰（preview/quality 标签）
```
