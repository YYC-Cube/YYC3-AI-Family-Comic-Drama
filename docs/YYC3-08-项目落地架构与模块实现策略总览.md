| 基础设施组件 | 🟢 开源标准选型 | Milvus/Redis/PostgreSQL/Grafana 生态成熟 |

## 三、开源 vs 自研决策矩阵

### 3.1 按技术层级分类

| 技术层 | 组件 | 决策 | 开源选型 / 自研依据 |
| ------ | ---- | ---- | ------------------- |
| **大模型** | LLM 推理 | 🟢 开源 | DeepSeek-V4 / Qwen2.5-72B（vLLM 部署） |
| | 文生图 | 🟢 开源 | SDXL / Flux.1-dev + LoRA + ControlNet（ComfyUI） |
| | 图生视频 | 🟢 开源 | MiniMax-H3 / AnimateDiff（经网关纳管） |
| | 口型同步评分 | 🟢 开源 | SyncNet（双后端） |
| | TTS 语音合成 | 🟢 开源 | XTTS v2 / ChatTTS |
| | 人脸识别/特征 | 🟢 开源 | face_recognition / InsightFace（512 维特征提取） |
| | Embedding | 🟢 开源 | nemotron-3-embed-1b / bge-m3 |
| **基础设施** | 向量数据库 | 🟢 开源 | Milvus 2.4.5（IVF_FLAT + COSINE） |
| | 消息队列/流 | 🟢 开源 | Redis Stream（ACK/NACK/DLQ） |
| | 关系数据库 | 🟢 开源 | PostgreSQL + pgvector |
| | 缓存 | 🟢 开源 | Redis |
| | 监控可视化 | 🟢 开源 | Prometheus + Grafana |
| | Web 框架 | 🟢 开源 | FastAPI（后端）+ Next.js 16（前端） |
| | 任务队列 | 🟢 开源 | Celery + Redis |
| **自研核心** | 统一 AI 网关 | 🔴 自研 | OpenAI 兼容协议 + EWMA 路由 + 熔断（0379-World） |
| | 多 Agent 编排 | 🔴 自研 | ReAct-C 九步闭环 + A2A 通信（组件库 v2.1） |
| | 六阶段工作流 | 🔴 自研 | DAG + 状态机 + 断点续传 |
| | 一致性引擎 | 🔴 自研 | face_encoder(开源底) + anchor_guard + style_keeper |
| | 质检引擎 | 🔴 自研 | 三维评分（一致性/流畅度/节奏）+ 打回闭环 |
| | 数据反哺引擎 | 🔴 自研 | 播放数据采集 → 归因分析 → LoRA 微调触发 |
| | 路径归一/鉴权中间件 | 🔴 自研 | /mnt/nas 统一 + X-API-Key/JWT |

### 3.2 决策依据

**选开源的理由**：成熟度高、社区活跃、无差异化价值、避免重复造轮子。

**选自研的理由**：
1. 已有可复用资产（组件库 12 目录 + 0379-World 网关设计）
2. 是项目差异化护城河（一致性引擎直接决定爆款率）
3. 需要深度业务定制（漫剧六阶段工作流无通用方案）
4. 协议适配层必须自研（网关统一纳管异构上游）

## 六、自研模块设计要点

### 6.1 一致性引擎（自研护城河 · G3 核心）

```
face_encoder.py          → InsightFace/face_recognition 提取 512 维特征向量
                           存 NAS assets/characters/{id}/feature.npy
anchor_guard.py          → 生成前：加载角色特征向量锚定 prompt
                           生成中：ControlNet 姿态骨架约束
                           生成后：特征相似度校验 < 阈值自动重绘
style_keeper.py          → 风格种子 + 色彩配置（LUT）+ 笔触参数持久化
                           同角色跨镜头强制一致
```

**验收锚点**：人物一致性合格率 ≥80%（G3 门禁）

### 6.2 统一 AI 网关（自研核心 · G1 核心）

```
chat.py                 → OpenAI 兼容 /v1/chat/completions 代理
auth.py                 → X-API-Key + JWT 双鉴权
path_normalize.py       → Mac /Volumes/... → /mnt/nas/ 归一
adaptive.py             → EWMA（延迟+错误率+负载）自适应路由
circuit_breaker.py      → 3 败摘除 30s 半开熔断
```

### 6.3 六阶段工作流（自研核心 · G2 核心）

```
dag.py                  → 解析 conductor 01~06.yaml，校验依赖
state_machine.py        → pending → running → success/failed → rework
retry.py                → 失败重试（指数退避）+ 断点续传（NAS state/）
scheduler.py            → 优先级调度 + 昼夜错峰（preview/quality 标签）
```
