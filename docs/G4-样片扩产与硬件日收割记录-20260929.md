### 3.2 concat demuxer 混排缺陷根治（本轮关键工程发现）

- **现象**：ep02 成片音频流仅 9.57s（视频 12.53s）——c3 动态镜段整体静音；aresample=async 不可修复。
- **根因**：concat **demuxer** 在混排源（H3 32k stereo AAC + compose AAC）下音频 pts 断裂，尾部音频帧被丢弃；静态同质镜（首验）不触发。
- **修复**：改用 concat **filter**（解码域拼接，`-filter_complex` 逐镜 `aresample=32000` + `aformat=stereo` 统一后 `concat=n=3:v=1:a=1`），并在验证段新增「音频轨 vs 视频轨齐平判定（±100ms）」。
- **方法论四连结论**（TC-G4-003 定版追加）：流拷贝 ✗ → 半重编 ✗ → 全重编码（同质镜）✓ → **concat filter（混排镜）✓✓**。
- 诚实记录：ep03 首跑时长偏差 35.0ms FAIL（超容差 1.7ms），系 piper TTS 字节级非确定性 + 帧量化偶发，复跑 PASS（29.0ms），与首验 46ms 波动先例一致。
