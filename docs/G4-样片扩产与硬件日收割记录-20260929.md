### 3.2 concat demuxer 混排缺陷根治（本轮关键工程发现）

- **现象**：ep02 成片音频流仅 9.57s（视频 12.53s）——c3 动态镜段整体静音；aresample=async 不可修复。
- **根因**：concat **demuxer** 在混排源（H3 32k stereo AAC + compose AAC）下音频 pts 断裂，尾部音频帧被丢弃；静态同质镜（首验）不触发。
- **修复**：改用 concat **filter**（解码域拼接，`-filter_complex` 逐镜 `aresample=32000` + `aformat=stereo` 统一后 `concat=n=3:v=1:a=1`），并在验证段新增「音频轨 vs 视频轨齐平判定（±100ms）」。
- **方法论四连结论**（TC-G4-003 定版追加）：流拷贝 ✗ → 半重编 ✗ → 全重编码（同质镜）✓ → **concat filter（混排镜）✓✓**。
- 诚实记录：ep03 首跑时长偏差 35.0ms FAIL（超容差 1.7ms），系 piper TTS 字节级非确定性 + 帧量化偶发，复跑 PASS（29.0ms），与首验 46ms 波动先例一致。

## 二十、生产域锚定三轴再校准：配置优化证伪，能力边界定位（v1.6.0 追加，HANDOFF 34.4 P1 执行）

### 20.1 实验设计（生产链同参，run_anchor_domain_recal.py）

纯 IPA 链（combo 生产域负交互已证伪）三轴网格，生产链同参（adapter 工作流 1024/负向空/分镜 prompt=`REF_STYLE+shot.description`/镜头稳定种子 sid×7+1000），2 生产镜头（ep01-001/002），insightface 余弦 vs hero_base。轴A 权重窗 {0.50/0.85/1.00}（w0.15 复用 ctrl manifest）；轴B 构图约束后缀；轴C 分辨率 512 对照。首战 6/10 中断（CTRL_BASELINE 混入字符串键 TypeError），续跑改造：已有产物直接评分复用 + COMFYUI_TIMEOUT 1800s + 单镜失败不中断。

### 20.2 三轴实测结果（10 镜，1024×8 + 512×2）

| 轴 | 配置 | mean sim | 判定 |
| ---- | ---- | ---- | ---- |
| A 权重窗 | w0.15（ctrl 基线） | **0.7423** | 全场最优 |
| A 权重窗 | w0.50 / w0.85 / w1.00 | 0.6946 / 0.6851 / 0.6634 | 单调递减 |
| B 构图约束 | w0.15 + 肖像后缀 | 0.7003（-0.042） | 无增益，证伪 |
| B 构图约束 | w0.50 + 肖像后缀 | 0.6818（-0.013） | 同上 |
| C 分辨率 | 512（w0.15） | 0.6469 | **反优于预期** |

### 20.3 科学结论（诚实报告）

- **轴A**：权重窗单调递减，弱 IPA w0.15 生产域最优（与离线域结论同向）——现行 `--ipa-weight` 缺省 0.15 即实测最优配置，**零变更获实证背书**；
- **轴B**：构图约束后缀两权重下均略降（场景叙事被稀释）——该路线证伪；
- **轴C**：1024 反比 512 高 +0.095，「分辨率衰减」假设被实测推翻——生产分辨率不是锚定劣化原因；
- **收敛判定**：三轴均无法突破 0.85（全场最佳 0.7423 即 w0.15 基线自身）——生产域 100% 拒绝率根因 = **PLUS FACE 在场景叙事 prompt 域的身份保持能力边界（模型能力问题，非配置问题）**；破局路线 = 更强身份保持模型（InstantID/PuLID 类）替换评测，列下轮候选；
- 留证：tc-anchor-recal-20260930.json（含结论字段）+ recal_*.png ×10。
