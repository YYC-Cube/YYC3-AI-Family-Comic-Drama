# 🧩 自研 ComfyUI 节点包对标清单（路线C）

> 情报源：[docs/12](12-DGXSpark-ComfyUI-H3部署包深度分析.md) §4.1 · 契约真源：[packages/manifest-schema/src/index.ts](../packages/manifest-schema/src/index.ts)
> 设计原则：**zod 契约单一真源不变**——上游 workflow JSON 仅作字段参照，所有 I/O 经我们的 JSON Schema 互验；本清单全部设计为自主实现，不依托上游代码/许可证。

## 一、上游 workflow JSON → zod 契约字段映射（实测 `h3-dense-baseline.json`）

| ComfyUI 节点输入 | 语义 | 我们的 zod 契约落点 | 状态 |
| ---- | ---- | ---- | ---- |
| `MiniMaxH3ImageToVideo.prompt/width/height/length` | 生成参数 | `manifest.params.{prompt,height,width,num_frames}` | ✅ 已有 |
| `RandomNoise.noise_seed` | 种子 | `records[].seed` | ✅ 已有 |
| `BasicScheduler.steps/denoise` | 采样 | `params.num_inference_steps` | ✅ 已有 |
| `UNETLoader.unet_name / CLIPLoader.clip_name / VAELoader.*` | 模型栈选择 | `manifest.model.{pipeline,variant}` + **建议扩展 `params.model_stack`** | ⚠️ 扩展点 |
| `SaveVideo.filename_prefix` | 产物定位 | `records[].video_path`（相对批次根） | ✅ 已有 |
| `KSamplerSelect.sampler_name` | 采样器 | `params.sampler` | ⚠️ 扩展点 |
| （上游无对应） | 平台宿主 | `params.host`（schema_version=2，docs/10 §6.4 双机 A/B） | 📌 已规划 |
| （上游无对应） | 加速档位 | **新增 `params.quality_tier`: `preview\|full`**（本次快预览档落契约） | 🆕 本次新增 |
| （上游无对应） | 超分后处理 | **新增 `params.upscale`: `{enabled, model, target}`**（360p→2× 情报落地） | 🆕 本次新增 |

**契约扩展执行规则**（沿用 `.passthrough()` + 双端同步）：读端不拒未知字段；写端（analyze_report.py / export_dashboard_data.py）新增字段时同步更新 zod 真源并重生成 JSON Schema（CI 漂移门禁自动把关）。

## 二、8 个 custom node 功能边界 → 自研节点对标

| # | 上游节点 | 功能边界 | 对我们路线C 的对标动作 | 优先级 |
| ---- | ---- | ---- | ---- | ---- |
| 1 | SolAttn_triton / sol-attn_Blackwell | SageAttn/SolAttn 加速（Blackwell 补丁已踩平） | 不复刻节点——**吸收结论**：CUDA 栈加速由 DiffSynth 侧 attention 后端选择承接（Phase 4 A/B 项）；节点包如做，引用其 Blackwell patch 思路自研 | P3 |
| 2 | Spectrum-MiniMax-H3 | 频域加速（与 SolAttn 正交，全栈叠加 1.36–1.62×） | 同上，作为 Phase 4 调优杠杆清单条目（docs/10 §5.2 增补） | P3 |
| 3 | VideoHelperSuite | 视频加载/合成/预览通用件 | 自研 `YYC3VideoIO` 节点：视频/音频 VAE 解码合成 + 产物路径输出，**输出字段直接绑定 `records[].video_path` 契约** | P1 |
| 4 | H3-Multishot | 多镜头连续性（AIO/MEMORY 两模式） | 自研 `YYC3Multishot`：镜头队列 + 前帧参考传递；manifest 每镜头一条 record，`params.multishot` 结构化 | P2 |
| 5 | H3_Keyframes | 关键帧驱动生成 | 自研 `YYC3Keyframes`：关键帧序列 + 时间戳映射 `records[].keyframes[]`（契约扩展点） | P2 |
| 6 | h3_sol_engine_ports（FBC+批量VAE） | First-Block-Cache 缓存 + 批量 VAE 解码 | **FBC 阈值情报已吸收**（thr=0.08 零命中，需 ~0.20+）；DiffSynth 侧如引入缓存以此为准；批量 VAE 并入 P1 VideoIO | P1（吸收）/P3（复刻） |
| 7 | KJNodes | 图像预处理/遮罩等通用工具集 | 按需逐个评估，仅复刻精评链路需要的（ref 图预处理） | P3 |
| 8 | （上游 TE 加载变体）nvfp4/int8/bf16/Heretic | 文本编码器精度栈 + 无审查变体 | 契约 `params.model_stack` 枚举固化（nvfp4/int8/bf16）；Heretic **不纳入**（内容合规红线，智云守护审核链路不兼容） | P1（栈枚举）/🚫（Heretic） |

> 🚫 **合规红线**：Heretic 无审查 TE 与 YYC³ 智云守护内容审核链路冲突，节点包永不提供；stockte 官方 TE 为唯一基线。

## 三、自研节点包 v0.1 范围（DGX 到货后启动，预计 1-2 周）

```
yyc3-comfyui-nodes/
├── __init__.py               # NODE_CLASS_MAPPINGS 注册
├── yyc3_video_io.py          # P1：VAE 解码合成 + CreateVideo/SaveVideo 对标
├── yyc3_manifest_out.py      # P1：节点图产物 → manifest.json（zod 契约互验）
│                             #    每次运行调 validate_manifest.py 双端校验
├── yyc3_ref2va.py            # P1：Ref2VA 节点（参考图+prompt+seed → 视频+音频）
├── yyc3_multishot.py         # P2：多镜头队列
├── yyc3_keyframes.py         # P2：关键帧驱动
└── workflows/                # 我们自己的预调工作流（preview/full 双档）
```

**验收门禁**（沿用 CI 五检查 + 新增）：
- [ ] `yyc3_manifest_out` 产出的 manifest 100% 通过 `validate_manifest.py`（契约互验）
- [ ] preview/full 双档工作流在 GB10 实机 A/B（锚点：docs/12 表 2.1）
- [ ] 产物自动进 NAS 归档通道（archive_to_nas.sh --manifest-only 联动）
