# 🎯 项目闭环预期状态及拓展分析

> 定位：回答三个问题——**闭环跑顺之后系统长什么样（终态定义）？各指标预期到多少（量化目标）？再往上长能长成什么（拓展方向）？**
> 与 [docs/04](04-演进规划与闭环优化机制.md) 的关系：04 讲「怎么走」（路线），本文讲「走到后」（终态）与「走完还能去哪」（拓展）。

## 一、闭环成熟终态定义（Target State）

### 1.1 终态全景图

```text
┌─────────────────────────────────────────────────────────────────┐
│                 MiniMax-H3 数字人生产线 · 终态                    │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  【输入层】ref_images 资产库（版本化）+ 台词脚本 + 模板库 v2      │
│      ↓                                                          │
│  【生成层】批次隔离 + manifest 驱动 + 断点续跑 + 双权重自动选型    │
│      ↓                                                          │
│  【评估层】口型分 + 人脸一致性分 + 耗时/内存基线（100% 客观自动）  │
│      ↓                                                          │
│  【精评层】仅 Top5 候选进入人工成对比较（Win Ratio）               │
│      ↓                                                          │
│  【分析层】背离检测 + 缺陷归因 + 趋势对比（analysis_result）       │
│      ↓                                                          │
│  【回流层】最优 seed 自动回写 + 模板调参建议 + 回归集防劣化        │
│      ↓                                                          │
│  【看板层】实时面板（真数据）+ 缺陷预警 + 多批次汇总              │
│      ↓                                                          │
│  【宏闭环】月度复盘 → 演进路线滚动调整 → 训练闭环（LoRA）接入      │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 终态行为特征（可验收）

| 特征 | 验收口径 |
| ---- | ---- |
| **一次输入，三份产出** | 一条命令（pipeline_auto）后：视频文件 + manifest 全字段记录 + analysis_result 分析报告 |
| **零重复劳动** | 人工只做两件事：把参考图放进目录、给 Top 候选打分。其余全自动 |
| **任何中断可续** | 断电/杀进程后重跑同命令，已成功任务跳过，失败任务重试 |
| **变更可对比** | 换权重/改环境/调提示词后，回归集 9 样本自动跑，指标对比表自动生成 |
| **劣化有预警** | 连续 2 批次同一缺陷 ≥30%，或客观/主观分背离，面板高亮 + 给出调参方向 |
| **数据可追溯** | 任意一个 mp4 能反查：哪张参考图、哪个 seed、哪个 prompt、何时生成、耗时内存、客观分、人工分 |

### 1.3 各阶段量化预期（北极星指标分解）

| 指标 | 现状 | Phase 1-2 后（1个月） | Phase 3-4 后（季度） | 依据 |
| ---- | ---- | ---- | ---- | ---- |
| 批次平均人工分 | 无基线 | 建立基线（预计 6.5±） | **8.0+** | docs/04 北极星 |
| 人工打分样本占比 | 100% | **<40%** | <25% | 客观分初筛 + 成对精评 |
| 单视频生成耗时 | ~468s/it × 50（待真实基线） | 基线确立 + 权重选型优化 | **-40%**（步数蒸馏+选型） | T3 系列 |
| 变脸+手崩缺陷率 | 无数据 | 自动可测 | **<15%** | T2.2 一致性分 |
| 客观/主观相关系数 | 无数据 | **>0.6**（启发式可信） | >0.75（SyncNet 校准） | T2 验收 |
| 无效迭代批次占比 | 未知（估 50%+） | 可测 | **<20%** | 4.2 触发规则 |
| 断点续跑成功率 | 已实现 | 100%（双确认机制） | 100% | T1.1 已验收 |

## 二、闭环运转的经济性分析

### 2.1 一个迭代周期的时间账（终态 vs 现状）

以「10 参考图 × 6 seed 量产批次」为例：

| 环节 | 现状方式 | 终态方式 | 节省 |
| ---- | ---- | ---- | ---- |
| 生成 | 相同（GPU 时间不变） | 相同 + 断点续跑兜底 | 中断零损失 |
| 评分 | 人工看 60 个视频打分 ~3h | 自动分全量 + 人工评 5 对 ~20min | **~89%** |
| 选 seed | 人工翻记录 ~30min | 自动回写 ~0min | 100% |
| 劣化发现 | 下批次人工察觉（滞后1批） | 回归集当批预警 | 提前 1 批 |
| **每批次人工总投入** | **~4h** | **~30min** | **~87%** |

### 2.2 数据资产的复利效应

- 每批次 manifest 都是**可训练数据集**的候选池：高人工分样本（≥8 分）自动沉淀为 LoRA 微调正样本
- 3 个月稳定运转后预计积累：100+ 高分视频 + 完整参数-结果对照表 → 直接喂 Phase 5 训练闭环
- **这是本闭环最深层的价值：生产过程本身就是数据飞轮的燃料**

## 三、拓展分析（Expansion）

### 3.1 拓展方向总览（按价值 × 可行性排序）

| 方向 | 内容 | 价值 | 可行性 | 依赖 |
| ---- | ---- | ---- | ---- | ---- |
| **E1 多镜头长视频** | 首尾帧引导串联多片段（T4.1），口播长视频自动分镜 | ★★★★★ | 高（H3 原生能力） | P4 |
| **E2 LoRA 角色定制** | 高分样本回流训练，锁定特定主播形象 | ★★★★★ | 中（128G 可训） | P5 + 数据积累 |
| **E3 多参考图一致性** | 9 图参考（正面/侧面/半身），解决侧脸崩坏 | ★★★★ | 高（改 references 构造） | T4.2 |
| **E4 批量并行化** | CPU 评分与 GPU 生成流水线重叠；多批次错峰 | ★★★ | 高 | 现有架构即可 |
| **E5 API 服务化** | manifest+生成包成 FastAPI 服务，供上游业务调用 | ★★★★ | 中 | P6 后 |
| **E6 集群联邦** | 多台 Mac 组队列（ssh 队列分发批次） | ★★★ | 中 | manifest 云同步 |
| **E7 实时数字人** | 蒸馏/加速后探索流式生成（直播场景） | ★★★★★ | 低（当前算力不足） | 依赖 E 系列加速成果 |

### 3.2 重点拓展 E1 详解：多镜头口播生产线

**场景**：5 分钟口播视频 = 15 个镜头，逐镜生成、首尾帧衔接、自动拼接。

```text
镜头N 生成（尾帧状态）──┐
                        ├──→ 镜头N+1 以「首帧=上一镜尾帧」引导生成 → 口型/身份天然连续
台词按句切分 + 分镜模板 ─┘
```

- 技术上 H3 FL2VA 的 first_frame/last_frame 原生支持，社区已有 chain-graft 实验先例
- 闭环数据直接复用：每个镜头走同一套「生成→评分→挑选」微流程
- **这是把「单镜头生产线」升级为「节目级生产线」的关键跃迁**

### 3.3 重点拓展 E2 详解：数据飞轮

```text
量产批次 → manifest 沉淀高分样本 → 数据集准备工具（T5.1：切分/caption/缓存）
    ↑                                        ↓
形象越来越稳定、口型越来越准  ←  LoRA 训练（T5.2）→ 回归集验证（T5.3）
```

- 量化预期：50+ 高分样本 LoRA 后，人物一致性（T2.2 指标）预计 +15~25%，同时可缩短推理步数（LoRA 收敛快）
- 风险对冲：LoRA 后必须过回归集，劣化 >5% 自动回滚（docs/04 规则三）

### 3.4 拓展的节奏建议

```text
现在 ──→ P0 收官闭环验证 ──→ E4 并行化（顺手做）──→ E1 多镜头（产品化跃迁）
                              ↓
                    数据积累 3 个月 ──→ E2 LoRA 飞轮 ──→ E5 API 服务化（对外输出）
```

**克制原则**：E1 之前不碰 E5/E6/E7。闭环未稳就服务化，等于把不稳定放大给外部。

## 四、终态自检清单（每月复盘用）

- [ ] 一条命令跑通全链路，人工只做放图 + Top 精评
- [ ] manifest 全字段真实非空，面板与实际一致
- [ ] 回归集在最近一次变更后跑过且达标
- [ ] 客观/主观相关系数 >0.6
- [ ] 缺陷率、平均分、耗时的趋势曲线存在且被看过
- [ ] 高分样本正在自动沉淀（数据飞轮在转）
- [ ] docs/06 快照与 docs/04 第七章均为最新

> 三项以上不达标 → 回到 docs/04 按优先级补课，不启动新拓展。
