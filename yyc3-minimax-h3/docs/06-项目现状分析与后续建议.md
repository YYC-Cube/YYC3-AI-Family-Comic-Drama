## 二、与规划目标的差距分析（Gap）

对照 [docs/04](04-演进规划与闭环优化机制.md) 的 6-Phase 路线：

| Phase | 规划 | 当前完成度 | 剩余缺口 |
| ---- | ---- | ---- | ---- |
| P1 数据层 | manifest 面板 utils | **90%** | T1.2 面板接真数据 |
| P2 评估 | 自动评分双后端 | **70%** | T2.2 人脸一致性分、T2.4 回归测试集；SyncNet 权重未拉取（当前用启发式后端） |
| P3 推理优化 | 基线/复现/调优 | **40%** | 采集器已上线，等 batch01 出真实数据；T3.2 CPU RNG 复现、T3.3 水位调优未做 |
| P4 能力扩展 | 首尾帧/多参考图 | **0%** | 全部未启动（含 T4.1 首尾帧引导） |
| P5 训练闭环 | LoRA | **0%** | 依赖 P2 回归集先行 |
| P6 看板 | 数据 API/预警 | **0%** | 依赖 T1.2 |

**新发现的性能风险**（batch01 实测后已部分证实/修正）：

1. **NF4 反量化是 MPS 上的最大瓶颈（已证实）**：实测 278~468s/it（首 seed 含预热），稳态约 **3.2h/条（8s 视频）**。4bit→bf16 在 CPU 反量化，MPS 无 bitsandbytes GPU kernel。
2. **推论（待验证）**：Pruned 版（bf16 直载）大概率显著快于 NF4。A/B 实测（同 seed 同 prompt，manifest gen_seconds 对比）仍是 P0，快 ≥30% 则量产切 Pruned。
3. **产能规划口径**：以 3.2h/条 为基准做排产。日产 >6 条必须叠加手段：Pruned + 步数 50→30 试验 + 评分/生成流水线重叠。
4. **新观察项 av_offset**：SyncNet 报 -11/-15 帧，需人工核验主观口型错位感；若确认偏移，可研究 DiffSynth 推理侧音画相位对齐参数。
