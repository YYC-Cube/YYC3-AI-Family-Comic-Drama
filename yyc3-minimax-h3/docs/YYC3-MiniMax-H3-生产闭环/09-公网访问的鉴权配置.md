## 一、公网访问鉴权配置（API Key 模式）

### 1.1 设计原则

对齐 `api.0379.world` 统一网关安全契约，采用**X-API-Key 请求头鉴权**为主、URL 查询参数兼容为辅的模式，严格遵循：

- **内网免鉴**：10.0.0.0/24 生产网段直接放行，不校验密钥，保障内部节点与终端高效访问
- **公网强校验**：公网访问强制校验 API Key，无效统一返回 401，对齐全网关错误规范
- **密钥分级**：管理员/只读两级权限，最小权限原则，支持多密钥分场景分发
- **全量可审计**：所有公网访问记录密钥标识与请求 ID，纳入网关审计体系
- **响应一致**：鉴权失败统一携带 `X-YYC3-Upstream` 响应头，保持协议一致性

### 1.2 Nginx 完整配置

#### 第一步：定义密钥映射（http 块级别）

在 Nginx 配置的 `http` 块中新增密钥映射表（与现有 server 块平级）：

```
# ==============================================================
# H3 数字人面板 API Key 鉴权映射
# 管理：按需新增/吊销，nginx -s reload 生效
# 权限分级：admin 全权限 / readonly 仅查看
# ==============================================================
map $http_x_api_key $h3_access_granted {
    default 0;
    # 管理员密钥（全权限）—— 真值见网关密钥文件，禁止写入本文档
    "<API_KEY_ADMIN>" 1;
    # 只读密钥（仅查看面板与数据，用于团队共享）
    "<API_KEY_READONLY>" 1;
}

# ⚠️ 弃用（P1-S3）：URL 参数模式会将密钥泄入网关 access log 与浏览器历史，
# 仅作兼容保留说明，新接入一律使用 X-API-Key 请求头
map $arg_api_key $h3_access_granted_param {
    default 0;
    "<API_KEY_ADMIN>" 1;
    "<API_KEY_READONLY>" 1;
}

# 最终鉴权结果：内网白名单 OR 密钥校验通过
map "$remote_addr:$h3_access_granted:$h3_access_granted_param" $h3_allow {
    default 0;
    ~*^10\.0\.0\.: 1;  # 生产内网段免鉴权
    ~*^127\.0\.0\.1: 1; # 本地回环免鉴权
    ~*:1: 1;         # 请求头密钥通过
    ~*::1: 1;        # URL参数密钥通过
}
```

#### 第二步：更新 location 鉴权逻辑

替换之前 `/h3-dashboard/` 配置中的访问控制部分，完整 location 如下：

```
location /h3-dashboard/ {
    alias /mnt/nas/raid1-core/h3-dashboard/;
    index Ref2VA-流水线管理面板.html;
    autoindex off;

    # 统一响应头契约
    add_header X-YYC3-Upstream "h3-dashboard" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header Cache-Control "public, max-age=300" always;

    # 静态资源压缩
    gzip on;
    gzip_types text/html application/javascript application/json text/css;
    gzip_min_length 1024;

    # 全局限流
    limit_req zone=api_general burst=20 nodelay;

    # ========== API Key 鉴权逻辑 ==========
    if ($h3_allow = 0) {
        return 401;
    }

    # 统一 401 错误响应
    error_page 401 @h3_unauthorized;

    # 禁止敏感文件访问
    location ~* (\.git|\.env|\.md|backup/) {
        deny all;
        return 404;
    }

    # SPA 单页应用路由兼容
    try_files $uri $uri/ /h3-dashboard/Ref2VA-流水线管理面板.html;
}

# 401 鉴权失败标准化返回
location @h3_unauthorized {
    internal;
    add_header X-YYC3-Upstream "h3-dashboard" always;
    add_header Content-Type "application/json; charset=utf-8" always;
    return 401 '{"code":401,"message":"Unauthorized: Invalid or missing API Key","request_id":"$request_id"}';
}

# 独立 batches.json API 接口鉴权
location /h3-dashboard/api/batches.json {
    alias /mnt/nas/raid1-core/h3-dashboard/batches.json;
    add_header X-YYC3-Upstream "h3-dashboard-api" always;
    add_header Content-Type "application/json; charset=utf-8" always;
    add_header Cache-Control "no-cache" always;
    limit_req zone=api_general burst=30 nodelay;

    if ($h3_allow = 0) {
        return 401;
    }
    error_page 401 @h3_unauthorized;
}
```

### 1.3 密钥管理规范

| 管理项 | 规范要求 |
| --- | --- |
| **生成规则** | `前缀-场景-权限-时间戳-随机串`，长度 ≥ 32 位，禁止弱密钥 |
| **权限分级** | 管理员密钥：全权限，用于管理与集成   只读密钥：仅查看面板数据，用于团队共享、大屏展示 |
| **文件权限** | 密钥配置文件权限 `600`，仅 root 可读，纳入版本管理时脱敏 |
| **轮换机制** | 每 90 天强制轮换，旧密钥保留 7 天过渡期后销毁 |
| **审计追溯** | 网关日志记录密钥前 8 位与请求 ID，可追溯访问来源与时间 |
