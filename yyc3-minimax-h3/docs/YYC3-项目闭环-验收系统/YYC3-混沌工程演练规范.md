# YYC³ 混沌工程演练规范

## 一、设计目标

将混沌工程演练纳入 YYC³ 验收体系，定期验证系统在故障场景下的弹性与自愈能力，填补五高架构「高可用」维度的混沌工程空白。

| 目标 | 指标 | 验收标准 |
| ---- | ---- | -------- |
| 故障注入覆盖率 | 覆盖核心组件 15+ 类故障 | 每季度全覆盖一次 |
| 系统自愈成功率 | 自动恢复成功率 ≥ 95% | 无需人工介入 |
| 演练影响可控 | 演练不造成真实用户影响 | 演练流量隔离 |
| 改进闭环率 | 演练发现的问题 100% 跟进修复 | 30 天内关闭 |

---

## 二、故障注入场景矩阵

### 2.1 基础设施层

| 故障类型 | 注入方式 | 预期行为 | 验收标准 |
| -------- | -------- | -------- | -------- |
| 单节点宕机 | 停止 K8s Pod/Node | 自动迁移到备用节点 | 恢复时间 < 60s |
| 网络延迟 | 注入 500ms-3s 延迟 | 熔断保护触发 | 降级响应 < 5s |
| DNS 故障 | DNS 解析失败 | 自动切换备用 DNS | 服务不受影响 |
| 磁盘满 | 填充磁盘至 95% | 写操作告警+只读模式 | 不影响读操作 |

### 2.2 数据层

| 故障类型 | 注入方式 | 预期行为 | 验收标准 |
| -------- | -------- | -------- | -------- |
| 数据库主库故障 | 停止主库 | 自动切换从库 | RPO < 1min, RTO < 5min |
| 缓存穿透 | 清空 Redis | 触发 DB 查询 + 缓存重建 | DB 负载不超 2x |
| 向量库不可用 | 停止 Qdrant | 降级为关键词检索 | 搜索不中断 |
| 消息队列积压 | 暂停消费 5min | 积压告警 + 自动扩容消费者 | 恢复后 10min 消化完毕 |

### 2.3 AI 引擎层

| 故障类型 | 注入方式 | 预期行为 | 验收标准 |
| -------- | -------- | -------- | -------- |
| 模型推理超时 | 注入 30s 延迟 | 触发模型降级 | 返回兜底响应 < 3s |
| GPU OOM | 占满 GPU 显存 | 自动切换 CPU 推理 | 精度未降低 |
| Agent 注册中心异常 | 停止注册服务 | 存量 Agent 正常运行 | 新 Agent 无法注册但已有服务正常 |
| RAG 检索失败 | 停止向量库 | 降级为无知识库回答 | 标注「未检索到相关知识」 |

### 2.4 业务层

| 故障类型 | 注入方式 | 预期行为 | 验收标准 |
| -------- | -------- | -------- | -------- |
| 言启·千行高负载 | 注入 100x QPS | 限流 + 排队 | 熔断时返回友好提示 |
| 元启·天枢故障 | 停止中枢服务 | 存量任务正常完成 | 新任务排队等待 |
| 智云·守护失效 | 停止安全服务 | 降级为基础规则 | 不产生安全盲区 |
| Skill 调用雪崩 | 批量超时注入 | 熔断 + 降级 | 不扩散至其他 Skill |

│       ▼                                                         │

│       │                                                         │

│       │                                                         │
│       ▼                                                         │
│  7. 问题复盘 ───→ 产出演练报告，记录未达标项与改进措施            │

## 四、与验收体系的融合

### 4.1 演练与验收阶段对应

| 验收阶段 | 对应混沌演练 | 演练频率 |
| -------- | ------------ | -------- |
| 单元测试验收 | 单组件故障隔离验证 | 每次发布 |
| 集成测试验收 | 多组件联调故障场景 | 每次迭代 |
| 系统测试验收 | 全链路故障注入 | 每月一次 |
| 生产验收 | 生产环境故障演练（不影响真实用户） | 每季一次 |

### 4.2 演练验收报告模板

```markdown
## 混沌工程演练报告

### 基本信息
- 演练编号: CE-2026-07-001
- 演练日期: 2026-07-23
- 演练场景: 数据库主库故障自动切换
- 演练环境: 预发布环境

### 故障注入
- 注入类型: PostgreSQL 主库停止
- 注入时长: 180s

### 观测结果
| 指标 | 基线 | 故障中 | 恢复后 | 达标 |
| ---- | ---- | ------ | ------ | ---- |
| 读请求成功率 | 100% | 99.8% | 100% | ✅ |
| 写请求成功率 | 100% | 0% (符合预期) | 100% | ✅ |
| 切换时间 | - | - | 23s | ✅ (RTO<60s) |
| 数据丢失 | - | - | 0 | ✅ (RPO<1min) |

### 发现的问题
1. 告警通知延迟约 2min，需优化告警优先级
2. 应用连接池预热约 10s，建议预建连接

### 改进措施
| 问题 | 负责人 | 预计完成 |
| ---- | ------ | -------- |
| 优化告警通知优先级 | SRE 组 | 2026-07-30 |
| 应用连接池预建优化 | 架构组 | 2026-08-07 |
```
