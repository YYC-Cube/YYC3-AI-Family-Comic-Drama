# ⚠️ Mac M4 重要避坑清单

1. **内存管理**：mac统一内存共享，生成视频时尽量关闭Chrome、Final Cut等大内存软件
2. **散热**：M4 Max长时间推理风扇会满载，垫高底部，不要放在床上/软垫上
3. **bitsandbytes**：M系列新版macOS原生支持NF4量化，如果报bitsandbytes错误，执行：

```bash
conda install -c conda-forge bitsandbytes
```

1. **模型缓存位置**：默认在`~/.modelscope/`，72GB，确保硬盘剩余空间>100GB
2. **帧限制**：Ref2VA模式帧数必须满足 `num_frames % 17 == 5`，推荐124帧（官方默认）

# 常见报错快速排查

| 报错 | 原因 | 解决方案 |
| ---- | ---- | -------- |
| MPS not available | PyTorch版本过低 | 检查PyTorch版本，必须>=2.4，重装torch |
| safetensors读取失败 | 网络中断导致模型下载不全 | 删除`~/.modelscope`文件夹，重新运行脚本自动重下 |
| ffmpeg相关报错 | ffmpeg缺失 | `conda install ffmpeg` |
| bitsandbytes报错 | M系列量化库异常 | `conda install -c conda-forge bitsandbytes` |

# 🎬 提示词避坑要点（生成质量相关）

## 必须遵守

1. **景别优先半身**：半身人像 > 特写 > 全身，全身极易手部崩坏、肢体穿模
2. **动作幅度一定要小**：只允许眨眼、轻微点头；大幅度动作会造成人脸漂移
3. **光线固定**：全程写明「光照不变」，光影变化太大人物容易变脸
4. **台词尽量简短**：124帧（约15s）内控制台词长度，否则口型对齐变差
5. **参考图选择**：正面平视、光线均匀、干净背景的半身照；不要侧脸、强逆光
6. **不要堆砌形容词**：避免大量电影级、8k、史诗级词汇，会增加画面不稳定

## 禁止写入

- ❌ 镜头缓慢推拉运镜、镜头环绕、人物站起来、大幅度挥手、转头看旁边
- ❌ 画面风格多次切换（一会二次元一会写实）
- ❌ 多人物同框（单段视频优先只保留1个人物，多人物极易身份混乱）

## 进阶方向

- 🚀 **LoRA微调**：128G统一内存可以直接跑，不需要两阶段拆分；训练人物/风格LoRA可使用accelerate训练脚本
