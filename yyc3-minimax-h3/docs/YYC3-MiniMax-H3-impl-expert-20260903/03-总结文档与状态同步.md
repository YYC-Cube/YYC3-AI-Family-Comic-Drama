## 遇到的问题与解决方案

| 问题 | 解决方案 | 经验教训 |
| ---- | -------- | -------- |
| 🔴 preview 首跑 Metal 同步死等后进程静默死亡（无报错、records 空） | 根因 = 帧数违反 `%17==5`；修正后一次通过 | DiffSynth 非法帧数不报错而是 GPU 层死等——**P1 应在 pipeline 入口加帧数防御校验**（docs/06 TOP3 #3） |

| docs/06「Pruned 四件套已本地化」误记 | 本轮纠正为「仅 DiT 单件」 | 活文档的历史表述要随磁盘实况定期复核 |

| 终端复合命令 heredoc/管道悬挂（`dquote>`、输出丢失） | 拆分简单命令 + `printf > 文件` + `python /tmp/xx.py` 中转 | 复杂命令落临时脚本文件执行，可复跑可审计 |
