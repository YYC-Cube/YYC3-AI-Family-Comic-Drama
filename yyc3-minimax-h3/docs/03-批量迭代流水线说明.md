# 🔄 批量迭代流水线使用说明

> 完整闭环：`pipeline_auto.py` → 批次生成 → 人工打分 → 分析 → 更新Seed → 多轮迭代 → `export_multi_batch_summary.py` 跨批次复盘

## 脚本全景

| 脚本 | 位置 | 职责 |
| ---- | ---- | ---- |
| `pipeline_auto.py` | scripts/pipeline-tools | 一键流水线入口，自动批次号 |
| `analyze_report.py` | scripts/pipeline-tools | 解析report.md，统计评分+缺陷，输出analysis_result.md |
| `update_seed_list.py` | scripts/pipeline-tools | 自动把最优seed写回主脚本（自动.bak备份） |
| `clean_batch.py` | scripts/pipeline-tools | 清理批次output视频文件夹，保留md打分报告 |
| `export_multi_batch_summary.py` | scripts/pipeline-tools | 跨批次评分汇总对比表 |

## 流水线规则（必须遵守）

1. 主脚本 `seed_list = [数字,...]` **必须单行书写**，不能换行（update_seed_list.py 正则依赖）
2. 所有py文件放在同一目录
3. 每轮更新主脚本时自动生成 `.bak` 备份，出错可回滚
4. 人工打分环节无法自动化（必须人看视频填report.md）

## 单轮迭代流程

```text
1. python pipeline_auto.py           → 自动检测下一个批次号 batchXX
2. 调用 batch_ref2va_nf4.py --batch 01
   - 自动创建 output_batch01/（视频隔离目录）
   - 视频保存到此文件夹，生成 report_batch01.md（含视频相对路径）
3. 暂停，人工打开 report_batch01.md 填写【评分】+【缺陷标签】
4. 回车 → analyze_report.py --batch 01 生成 analysis_result_batch01.md
5. update_seed_list.py --batch 01 更新主脚本 seed_list
6. 再次运行 pipeline_auto.py 自动进入 batch02，旧批次全部保留
```

## 模式开关（pipeline_auto.py 配置区）

- `AUTO_AFTER_GENERATE=False`（默认，推荐）：生成后暂停，等人工填写report再继续
- `AUTO_AFTER_GENERATE=True`：全自动，适合已提前填好上一轮report的场景
  > ⚠️ 新生成视频后若没有人工打分，分析脚本会读到空评分，无法算出有效最优seed

## report.md 表格规范

| 参考图 | Seed | 状态 | 视频相对路径 | 时间 | 评分(1~10) | 缺陷标签 |
|--------|------|------|--------------|------|------------|----------|
| person_a.jpg | 42 | SUCCESS | output_batch01/seed_42.mp4 | 14:30:21 | 9 |  |
| person_a.jpg | 10 | SUCCESS | output_batch01/seed_10.mp4 | 14:35:02 | 6 | 手崩,抖动 |
| person_b.png | 42 | FAILED | - | 14:40:11 |  |  |

- 状态：`SUCCESS` / `SKIPPED`（断点跳过）/ `FAILED`（推理报错）/ `READ_FAILED`（图片读取失败）
- 缺陷标签可选：`变脸`、`手崩`、`抖动`、`口型错位`，多标签逗号分隔，无缺陷留空
- 脚本不会覆盖手动填写的评分；重复运行只追加新行

## 封面预览（可选增强）

主脚本增加 `opencv-python` 依赖（`pip install opencv-python`），生成视频后自动提取首帧保存为jpg封面，report中嵌入markdown图片链接，打分不用打开视频。

核心代码片段（新增/替换到主生成脚本）：

```python
import cv2

def extract_first_frame(video_path: Path, cover_path: Path):
    """提取视频首帧保存为jpg封面"""
    cap = cv2.VideoCapture(str(video_path))
    ret, frame = cap.read()
    if ret:
        cv2.imwrite(str(cover_path), frame)
    cap.release()
    return ret

# 表头新增【预览封面】列
f.write("| 预览封面 | 参考图 | Seed | 状态 | 视频相对路径 | 时间 | 评分(1~10) | 缺陷标签 |\n")

# 写入表格行，嵌入markdown图片
f.write(f"| ![封面]({rel_cover}) | {ref_img_name} | {seed} | 成功 | {rel_video} | {datetime.now().strftime('%H:%M:%S')} |  |  |\n")
```

## 批次参数改造要点（--batch 传递）

- `batch_ref2va_nf4.py`：argparse 接收 `--batch`，输出目录 `output_batch{batch}`，报告 `report_batch{batch}.md`
- `analyze_report.py`：接收 `--batch`，读取 `report_batch{batch}.md`，输出 `analysis_result_batch{batch}.md`
- `update_seed_list.py`：接收 `--batch`，读取 `analysis_result_batch{batch}.md`
- `pipeline_auto.py`：自动扫描 `report_batch*.md` 取最大批次号+1，向下游传递 `--batch`

## 跨批次复盘

多轮迭代后运行：

```bash
python export_multi_batch_summary.py
```

生成 `multi_batch_summary.md`，包含6张表：

1. **各批次总览**：成功/失败/跳过数、平均分、最高分
2. **跨批次Seed评分横向对比**：同一参考图+同一Seed在各批次的评分/状态/缺陷并排
3. **各参考图每批次最优Seed**：快速定位每个人物每轮最佳参数
4. **全局Top10高分样本**：跨所有批次排名
5. **缺陷标签跨批次统计**：变脸/手崩/抖动/口型错位出现次数
6. **迭代结论与建议**：平均分趋势、最高频缺陷、推荐下一轮Seed

该脚本独立运行，兼容带/不带「预览封面」列的报告，只读取md，不修改任何已有脚本和报告。

## 清理硬盘（保留打分记录）

```bash
# 删除batch01视频（保留report_batch01.md）
python clean_batch.py --batch 01

# 删除所有批次output视频文件夹（全部md保留）
python clean_batch.py
```
